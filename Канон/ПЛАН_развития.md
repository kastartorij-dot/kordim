# Кордим — план развития

Собран 04.11.2026 по заданию [08](08_Задание_единый_план_развития.md), обновлён 06.11. Это не канон. План — оглавление работы: подробности остаются в исходных файлах по ссылкам. На сайте — раздел «План» (собирается из этого файла, проценты считаются по отметкам).

**Как вести:** закрыл пункт — поставь `[x]` и дату `✓ ДД.ММ`, затем `node Канон/_Сборка/export-plan.mjs`. Новый вопрос — подробно в [очередь](02_Очередь_и_вопросы.md), сюда одну строку. Охват: лор, мир, герои, проза, справочник и сайт. Игры (ПОРТ, генератор историй, вкладка «Игра») ведутся отдельно, в `Игры/Порт/`.

**Отметки:** `[x]` сделано · `[~]` частично (считается за половину) · `[ ]` не сделано · `[3/13]` сделано 3 из 13 · `[-]` снято. Процент раздела — средняя готовность его пунктов.

**Трудоёмкость:** · час · ·· полсессии · ··· сессия и больше. **А** — нужен ответ автора.
