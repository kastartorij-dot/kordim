# Концепт: как править канон, синхронизировать и открывать с телефона

Черновик 15.09. Ничего из этого ещё не сделано. Макет вкладки «Канон» — `Игры/Сайт/Прототипы/canon.html`.

---

## 1. Главная проблема сейчас

Одна правка мира сейчас живёт в трёх-четырёх местах: мастер (400 КБ текста), компакт, данные вики
(`Игры/Сайт/Приложение/data`), а ещё копия файлов в проекте Claude на телефоне. Всё это я догоняю вручную.
Отсюда расхождения. Например, граф и старый справочник до сих пор врут про Гильдию.

**Решение: один источник и сборка.** Правишь в одном месте, остальное собирается автоматически и не может отстать.

## 2. Где живёт канон

Мастер режется на **блоки**: одна запись — один файл.

```
Канон/
  Записи/
    00-география.md
    16-экономика.md
    36-контора-сайдена.md
    ...
    52-отряд-лихо.md
  Герои/  грейс.md, никто.md, связь.md
  Правила/ роли.md, стиль.md, физика-боя.md ...
  входящие/            ← заметки и предложения, ещё не канон
  журнал.md            ← все утверждённые правки по порядку
  00_КАНОН_Мастер_Кордим.md   ← СОБИРАЕТСЯ из блоков, руками не правится
  01_Компакт_канон.md         ← СОБИРАЕТСЯ из блоков
  02_Очередь_и_вопросы.md
```

У каждого блока шапка с полями:

```
---
id: 36
title: Контора Сайдена и заказы
section: Фракции
status: канон            # канон · открытый вопрос · черновик
keys: контора, заказ, жетон, поручительство...
links: [brok, marra, sedrik, capital]   # id людей и мест из вики
changed: 2026-09-13
compact: |
  Товар конторы — слово Сайдена...    ← сжатая версия для компакта
---
Полный текст записи.
```

Что это даёт:
- **Мастер и компакт становятся продуктом сборки.** Скрипт склеивает блоки в тот же порядок, что сейчас: мастер из полного текста, компакт из поля `compact`. Компакт больше не отстаёт, потому что его сжатая версия лежит в том же файле, что и полная.
- **Вики читает те же блоки.** Вкладка «Канон» показывает их напрямую, чипы людей и мест берутся из `links`.
- **Одна правка трогает маленький файл**, а не 2600 строк. Легко смотреть, откатывать и сравнивать.

Как делятся мастер-блоки и данные вики:
- **Цифры и структура живут в `Игры/Сайт/Приложение/data`**: годы, цены, маршруты, население, связи.
- **Смысл и правила живут в блоках**: как устроена контора, что можно в сцене, тон.
- Блок может сослаться на цифру из данных, например `{{price:horse}}`. При сборке туда подставится значение из `goods.js`, так что цена записана в одном месте.
- Приложение «Опорные цифры» будет собираться из данных целиком.

**Проверка при сборке.** Скрипт падает с понятной ошибкой, если:
- `links` ссылается на несуществующего человека;
- в тексте всплыли снятые вещи вроде «Гильдии наёмников», «гримдарка» или жетона у Никто. Список ведётся в `Канон/запреты.txt`.
- у записи пустой `compact`.

## 3. Как проходит правка (ПК, Claude Code)

```
ты: «у Торна шрам на левой, а не на правой»
      │
я: ищу по всем блокам, данным вики, прозе и очереди, где это встречается
      │
я: показываю КАРТОЧКУ ПРАВКИ
   П-0044 · Торн, сторона шрама
   было → стало (дифф по каждому месту)
   затронуто: Канон/Записи/40-торн.md, data/Люди/thorn.js
   конфликты: в Проза/… шрам справа — поправить?
   компакт: меняется одна строка
      │
ты: «да» / «да, но прозу не трогай» / «нет»
      │
я: вношу → строка в журнал.md → сборка (мастер, компакт, проверка) → сохраняю версию
```

Правила:
- **Без «да» ничего не вносится.** Мелкие опечатки можно пачкой одной карточкой.
- **Одна правка = одна запись в журнале = одна версия в истории.** Любую можно откатить отдельно.
- Если правка спорит с другим местом канона, это видно в карточке **до** «да», а не всплывает потом.
- Решения без ответа не теряются: уходят в `02_Очередь_и_вопросы.md`.

## 4. Синхронизация: git + GitHub — основа всего

Всё остальное (телефон, сайт, проект Claude) держится на одном: папка `Кордим` становится
**приватным репозиторием на GitHub**. Это бесплатно и видно только тебе.

```
             ┌────────────── GitHub (приватный репозиторий «Кордим») ──────────────┐
             │   Канон/записи, Игры/Сайт/Приложение, Мини-игра, картинки, журнал               │
             └──────▲───────────────▲──────────────────▲──────────────▲────────────┘
                    │ push          │ push             │ синк          │ деплой
      Claude Code на ПК   Claude Code в облаке   Проект Claude     Сайт вики
      (как сейчас)        (с телефона, ПК выкл)   (телефон, чат)    (телефон, браузер)
```

При каждом сохранении GitHub сам запускает сборку: мастер, компакт, проверка. Сайт обновляется через минуту.
Не важно, откуда пришла правка: с ПК, с телефона или с сайта.

### 4а. Проект Claude на телефоне

Claude.ai умеет подключать **GitHub-репозиторий как знания проекта**. Тогда файлы не загружаются руками:
- в проект подключаются `Канон/00_КАНОН…`, `01_Компакт…`, `02_Очередь…`, `журнал.md`;
- после правок в проекте нажимается «Синхронизировать», и файлы свежие.

Это одностороннее: проект **читает** канон, но писать в репозиторий из обычного чата Claude не может.
Поэтому правки с телефона идут одним из трёх путей (от лучшего к простому):

1. **Claude Code в облаке с телефона — полный путь.** В приложении Claude есть раздел Code: он работает
   с GitHub-репозиторием на серверах Anthropic, и ПК не нужен. Там всё как здесь: карточка правки, «да»,
   внесение, сборка. **Проверь у себя**, есть ли вкладка Code в приложении, — от этого зависит, нужен ли вообще путь 2.
2. **Обычный чат в проекте + «Входящие» на сайте.** В инструкции проекта прописано: в конце обсуждения
   Claude выдаёт блок `ИТОГ ПРАВОК` в фиксированном формате. Ты копируешь его во «Входящие» на сайте вики
   (см. п. 5), и он ложится в `Канон/входящие/`. В следующей сессии Claude Code я разбираю входящие
   карточками правок.
3. **Совсем без сайта.** Тот же `ИТОГ ПРАВОК` вставляешь сюда, когда сядешь за ПК.

Инструкцию для проекта Claude и формат `ИТОГ ПРАВОК` напишу вместе с разделом «Канон».

## 5. Вкладка «Канон» в вики

Макет: `Игры/Сайт/Прототипы/canon.html`.

**Чтение.**
- Слева разделы: Герои, Правила ведения, География, Фракции, Люди, Экономика, Быт, Хронология, Приложения.
- В центре блоки карточками. У каждого есть:
  - номер и статус цветом: канон, открытый вопрос, черновик;
  - дата последней правки;
  - чипы людей и мест со ссылками на их страницы.
- Поиск по тексту и ключам. Фильтр «что менялось за неделю».

**Заметка для Клода.**
- Кнопка у любого блока или абзаца. Пишешь «проверь, не противоречит ли это Лихо» или «тут хочу иначе, обсудим».
- Заметка ложится во «Входящие» с привязкой к месту.

**Предложить правку.**
- Блок открывается в редакторе: текст слева, как будет выглядеть — справа.
- Сохранение **не меняет канон**, а создаёт карточку-предложение с диффом.
- Канон меняется только после того, как я проверю связность, а ты скажешь «да».
- Так нельзя случайно сломать мир с телефона, а я вижу, что именно ты хотел.

**Журнал.**
- Лента утверждённых правок: дата, что, почему, какие файлы.
- Любую можно раскрыть и посмотреть дифф.
- Кнопка «откатить» тоже не действует сразу, а создаёт предложение.

**Входящие.**
- Очередь заметок и предложений со статусами: новое → разобрано → внесено или отклонено.
- Отсюда же вставляется `ИТОГ ПРАВОК` из чата.

Как сайт записывает, зависит от того, где он открыт:

| Где открыт | Куда пишет «Входящие» |
|---|---|
| ПК, `localhost:8791` | прямо в `Канон/входящие/` через `_serve.ps1` |
| Сайт в интернете | маленькая серверная функция делает запись в GitHub; ключ доступа лежит на сервере, не в странице |

## 6. Как открыть вики на телефоне без ПК

Проект статичный (HTML + JS, без сборки), поэтому его можно выложить почти куда угодно.
Варианты от лучшего:

### А. Cloudflare Pages + Cloudflare Access — рекомендую
- Сайт собирается из приватного репозитория при каждом сохранении.
- **Закрыт паролем:** вход по коду на твою почту. Бесплатно до 50 человек, можно дать доступ соавтору.
- Там же живёт серверная функция для «Входящих» (п. 5), так что сайт умеет записывать.
- Картинки (сейчас 180 МБ) влезают. Отдельный файл до 25 МБ, а у нас самый большой около 10 МБ.
- Мини-игра работает: ключ OpenRouter вводится в игре и хранится в браузере, в коде его нет.
  На телефоне ключ придётся ввести один раз.
- Нужно: аккаунт Cloudflare (бесплатный) и подключение репозитория. Настройка минут на 20, я распишу по шагам.

### Б. GitHub Pages
- Проще всего, но у приватного репозитория Pages только на платном GitHub.
- И сайт получается **открытым любому**, кто знает адрес. Для канона с тайнами Астернов это плохо.
- Записывать ничего не умеет.

### В. Артефакт на claude.ai
- Вики публикуется как приватная страница в твоём аккаунте Claude и открывается в приложении.
- Лимит 64 МБ, поэтому картинки нужно ужать: webp примерно в 10 раз меньше, всё влезет.
- Обновляется только когда я перепубликую из Claude Code, сам после правки не догоняет.
- Хорош как быстрый вариант «на сейчас», пока нет Cloudflare.

### Не подходят
- **Tailscale / проброс порта** — ПК должен быть включён.
- **Netlify / Vercel** — то же, что А, но без бесплатного пароля на весь сайт.

## 7. Порядок работ

| Шаг | Что | Зависит от тебя |
|---|---|---|
| 1 | git в папке, приватный репозиторий на GitHub | аккаунт GitHub |
| 2 | нарезать мастер на блоки, скрипт сборки мастера и компакта, проверка, `журнал.md` | — |
| 3 | сверить: собранный мастер = текущий мастер слово в слово | — |
| 4 | карточки правок и журнал в работе здесь, в Claude Code | — |
| 5 | подключить репозиторий к проекту Claude, написать инструкцию и формат `ИТОГ ПРАВОК` | нажать «подключить» |
| 6 | вкладка «Канон»: чтение, заметки, предложения, журнал, входящие | выбрать дизайн по макету |
| 7 | Cloudflare Pages + Access, функция записи во «Входящие» | аккаунт Cloudflare |
| 8 | проверить Claude Code в облаке с телефона на этом репозитории | посмотреть вкладку Code |

Шаги 1–4 полезны сразу, даже если до сайта не дойдём.
