# Игры и сайт Кордима

Всё, что относится к играм и сайту, лежит в этой папке.

| Папка | Назначение | Где править |
|---|---|---|
| `Порт/` | Игра «Порт Теней», документы, тесты и изображения | Здесь находятся действующие исходники ПОРТа |
| `Генератор_Историй/` | Отдельная мини-игра «Кордим: Хроники» с OpenRouter | `Index.html` и документы в этой папке |
| `Сайт/Приложение/` | Реестр мира: люди, места, канон, хроника, арки | Код и данные сайта |
| `Сайт/Изображения/` | Изображения реестра мира | Здесь хранятся картинки сайта |
| `Сайт/Игра/Порт/` | Публичная копия ПОРТа | Создаётся сборкой из `Порт/` |
| `Сайт/Игра/Истории/` | Публичная копия «Хроник» | Создаётся из `Генератор_Историй/Index.html` |

У каждой игры один источник. Публичные копии обновляются общей командой и проверяются по содержимому каждого файла; GitHub также выполняет эту проверку.

## Единый стандарт папок

Рабочие папки называются по-русски. Каждое слово начинается с заглавной буквы, между словами — подчёркивание: `Материалы_ИИ`, `Генератор_Историй`, `Приложение_Для_ПК`.

Исключения — служебные имена, которые требуют инструменты: `.git`, `.github/workflows`, `.claude`, `.vscode`, `src-tauri`, `src`, `icons` и вложенные папки платформенных иконок. Имена файлов и программные идентификаторы отдельному переименованию не подвергаются.

## Как поддерживать одну версию

Из корня репозитория `D:\AI\kordim`:

```powershell
git pull --rebase origin main
```

После правок исходников:

```powershell
npm --prefix Игры run publish
npm --prefix Игры run check
git add -A
git commit -m "Описание изменений"
git push origin main
```

Версия проекта определяется коммитом `main`. ПК и GitHub совпадают, когда `HEAD` и `origin/main` одинаковы, а `git status` сообщает об отсутствии несохранённых изменений. Сайт получает этот коммит после завершения автоматического деплоя Cloudflare.

## Открыть локально

Запустить `Сайт/_serve.ps1`, затем открыть:

- Реестр мира: `http://localhost:8791/Приложение/`.
- ПОРТ: `http://localhost:8791/Игра/Порт/`.
- Хроники: `http://localhost:8791/Игра/Истории/`.

Порядок разработки ПОРТа описан в `Порт/Документы/ПОРЯДОК_РАБОТЫ_И_ВЕРСИЯ.md`. Генерация через LLM требует ключа OpenRouter; проверка переноса не отправляет запросов к моделям.

Результаты проверки переноса и известные старые ошибки тестов: [ПЕРЕНОС_04_10_2026.md](Порт/Документы/Общие_Материалы/ПЕРЕНОС_04_10_2026.md).
