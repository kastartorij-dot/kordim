# Автопроверки Общаги

Команды из папки проекта:

```sh
python Инструменты/проверка_glb.py
python Инструменты/проверка_ссылок.py
python Инструменты/прогнать_проверки.py --godot "/путь/к/godot"
```

Первые две команды работают без Godot. Проверка GLB сверяет имена подвижных узлов, мебель, материалы и установленные бюджеты модели. Проверка ссылок проверяет простые относительные ссылки Markdown. Последняя команда импортирует ресурсы и последовательно запускает проверки Godot. Полные логи сохраняются в `builds/логи-проверок/`. В GitHub Actions эти проверки запускаются при изменениях проекта.

## Замер оптимизации

На одной и той же сцене в Godot 4.7.2 медиана шести построений статической коллизии сократилась с 743 до 656 мс. До и после коллизия содержит 316 739 треугольников. Замер проведён на Windows.

Клавиша P переключает облегчённый свет. В этом режиме отключаются только дополнительные тени. Солнце и основной плафон сохраняют тени. В двух парах коротких прогонов ночного режима при 1280×720 на RTX 3060 интервалы кадра перекрылись (2,10–2,43 мс в обычном режиме, 2,15–2,53 мс в облегчённом). Устойчивый прирост FPS на этом ПК не подтверждён.
