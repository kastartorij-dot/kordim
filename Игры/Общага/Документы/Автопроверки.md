# Автопроверки Общаги

Команды из папки проекта:

```sh
python Инструменты/проверка_glb.py
python Инструменты/проверка_ссылок.py
python Инструменты/прогнать_проверки.py --godot "/путь/к/godot"
```

Первые две команды работают без Godot. Проверка GLB сверяет имена подвижных узлов, мебель, материалы и установленные бюджеты модели. Проверка ссылок проверяет простые относительные ссылки Markdown. Последняя команда импортирует ресурсы и последовательно запускает проверки Godot. Полные логи сохраняются в `builds/логи-проверок/`. В GitHub Actions эти проверки запускаются при изменениях проекта.
