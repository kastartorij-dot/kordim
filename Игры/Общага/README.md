# Общага

Воссоздание комнаты автора, коридора, санузла, лоджии и двора. Самостоятельный 3D-проект вне мира Кордим.

## Запуск на ПК

Откройте [project.godot](project.godot) в Godot 4.7 (проект проверялся на 4.7.2), дождитесь импорта и нажмите **F5** в редакторе. Blender для запуска не нужен. Частота кадров ограничена 60 FPS. Чтобы открыть сцену для расстановки, выберите [scenes/dorm.tscn](scenes/dorm.tscn) и разверните узел «Модель».

| Клавиши | Действие |
|---|---|
| WASD или стрелки, Shift, пробел, Ctrl | Ходьба, бег, прыжок, приседание |
| E | Взаимодействие с предметом под прицелом до 2 м. На лоджии левая створка сдвигается вправо. Тумблер у монитора включает и выключает главный плафон. На стуле можно сесть, на кровати лечь. E или пробел возвращают в стойку |
| H, Esc, клик, F11 | Показать управление, освободить мышь, захватить её, переключить полный экран |
| 1–4 | Ракурсы комнаты, кровати, лоджии и двери |
| ЛКМ или E на ночнике | Открыть меню цвета, яркости и питания. Esc закрывает меню |
| L, N, B, P | Переключить режим освещения, цвет ночника, общий цвет лент и кулеров. P включает облегчённые тени |
| F5 / F9 в игре | Сохранить / загрузить прогулку |
| C, F, G | Достать и поджечь сигарету или убрать её, сделать затяжку, стряхнуть пепел |

Пеший маршрут проходит по комнате, лоджии и коридору. Перед проходом по коридору закройте дверь санузла.

Для зимнего режима нажмите **Esc**, затем кнопку **«Зимний режим»** справа вверху. Кнопка **«Режимы гирлянд»** открывает выбор эффекта и яркости. F5 сохраняет эти настройки вместе с прогулкой, F9 загружает их. Для запуска сразу зимой добавьте `-- --winter` к команде Godot.

## Сборка Windows

Установите экспортные шаблоны той же версии Godot. Из папки проекта запустите:

```sh
python Инструменты/сборка.py --godot "C:/путь/к/Godot_console.exe"
```

ZIP для Windows, ZIP с проектом и отчёт с контрольными суммами появятся в локальной папке `builds/пакеты/`. Распакуйте Windows ZIP и запустите `Dorm.exe`. История прежних пакетов — в [архиве](Архив/README.md). Частные референсы описаны в [карте кадров](Фото_референсы/Карта_кадров.md).
