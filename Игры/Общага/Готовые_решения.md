# Готовая основа вместо разработки всех механизмов вручную

Указание автора 15.11.2026: искать готовое и подгонять под нашу комнату.
Планировку, зелёные покрывала, отсутствие гитары и авторскую сторону балконной
двери сохранять. Существующую сцену не заменять чужой типовой комнатой.

## Кандидаты, проверенные по первичным страницам

- **COGITO**: https://godotengine.org/asset-library/asset/2536
  MIT, в опубликованной карточке версия 1.1.6 для Godot 4.5.1. Есть контроллер
  игрока, компоненты взаимодействий, примеры дверей/ящиков/переноса предметов,
  сохранения. Основной кандидат для отдельной пробной сцены с нашей моделью.
  Совместимость с 4.6.3, Compatibility и импортом GLB пока не проверялась.
  Версию брать из официального репозитория по ссылке карточки, не случайного форка.
- **First Person Horror Template**:
  https://github.com/AdeelTariq/First-Person-Horror-Template
  Автор указывает Godot 4.5, контроллер, двери/ящики с перетаскиванием и модульность;
  система взаимодействий WIP. В комплекте также Talo analytics, меню и другие
  плагины. Перед переносом сверить LICENSE/CREDITS и зависимости; весь проект
  автоматически к нашей комнате не подключать. Кандидат для сравнения с COGITO.
- **Poly Haven**: https://polyhaven.com/models
  Готовые бытовые модели, PBR-текстуры и HDRI. Лицензия CC0 разрешает в том числе
  перераспространение: https://polyhaven.com/license — подходит публичному Git.
  Часть материалов и мелочи уже используется; см. textures/ИСТОЧНИКИ.md.

## Как продолжать

1. Проверить COGITO на отдельной маленькой сцене: наш GLB, игрок, одна дверь,
   один ящик, сохранение их состояния. Сравнить управление и стоимость адаптации
   с уже работающими 16 узлами, не переносить все системы шаблона сразу.
2. Для визуальных правок сначала искать готовые модели/материалы; проверять
   сходство по опорным кадрам и авторской схеме, масштаб, подвижные части и лицензию.
3. Подгонять расположение, размеры и цвета. Самостоятельно моделировать только
   отсутствующее или особенно узнаваемое, если переделать готовое сложнее.
4. Для платных ассетов прежде покупки показать конкретный набор и цену автору.
   Перед включением исходников в публичный Git проверить право перераспространения.

Это подбор кандидатов, не отметка о внедрении. Нынешние scripts/player.gd и
scripts/movable.gd — собственная небольшая реализация; COGITO ещё не установлен.
