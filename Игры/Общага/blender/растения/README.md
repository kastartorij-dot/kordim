# Модели зелени двора

Pine_2, Pine_4 и Bush_Common из [Stylized Nature MegaKit](https://quaternius.com/packs/stylizednaturemegakit.html), Quaternius, [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). Файлы glTF и текстуры взяты из [зеркала набора](https://github.com/tilakpatell/tilakverse-assets/tree/main/quaternius/stylized-nature-megakit/glTF). Геометрия и материалы перенесены в GLB с вшитыми текстурами. Атлас листвы Bush_Common переведён из красного в зелёный с сохранением контура по альфа-каналу. Размеры и повороты задаёт генератор двора.
