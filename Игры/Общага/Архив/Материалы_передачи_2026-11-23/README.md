# Материалы передачи от 23.11.2026

Этот каталог хранит кандидатов для дальнейшей работы над «Общагой». Подробности по фото собраны в [сверке](../../Документы/Фотосверка_2026-11-23.md).

## Предметы

Из `obshaga_complete_pack.zip` сохранены 13 моделей для примерки. В `Предметы/` лежат три куртки, белые кроссовки и шлёпанцы, кепка, плафон прихожей, синяя сумка, гладильная доска, два полотенца, поддон и санузел целиком.

Раковина, унитаз, чёрные кроссовки, пакет с бутылками, СВЧ и чайник побайтно совпали с файлами в `models/предметы/`. Они уже расставлены в локальной рабочей сцене на момент сверки. Скрипты автоподстановки из ZIP рассчитаны на массовое скрытие старых узлов по префиксам. Модели стоит примерять по одному предмету с проверкой масштаба, стыков и коллизий. Санузел целиком годится для сравнения планировки и отделки.

## БЦ «Асгард»

[Модель](Асгард/асгард.py) и [генератор текстур](Асгард/асгард_текстуры.py) перенесены из двух отдельных вложений. Синтаксис Python проверен. Для подключения нужно сверить контур и нумерацию рёбер, высоту и ориентацию фасадов с [панорамами двора](../../Фото_референсы/Двор_2026-11-23/README.md), затем проверить дневной и вечерний экспорт Blender. Размеры в скрипте оценочные.

## Код и сборки

Из архива с CI взяты три Python-проверки и workflow. Архивный тест надёжности зависит от предложенных в той копии изменений сохранений и освещения. Облегчённый свет, переработка коллизий и новый расчёт запросов взаимодействия требуют отдельных замеров и проверки на текущей сцене. В пакете замеров FPS и времени построения коллизий нет. В архивном упаковщике проверка наличия `.git` рассчитана на корень репозитория. «Общага» лежит внутри монорепозитория.
