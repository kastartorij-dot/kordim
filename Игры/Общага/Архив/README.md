# Архив Общаги

Актуальные команды и структура проекта — в [README](../README.md).

- [История разработки](История_разработки.md) — прежний README с подробностями о механиках, геометрии и проверках.
- [Заметки прошлых сессий](Заметки_прошлых_сессий.md) и [задание на вид из окна](Задание_на_вид_из_окна.md) — контекст ранних итераций.
- [Ранние рендеры](Ранние_рендеры/) и [снимки старых сборок](Материалы_старых_сборок/Скриншоты/) — сохранённые визуальные материалы. [Отчёт старой сборки](Материалы_старых_сборок/проверка.json) содержит её контрольные суммы.

Четыре прежних ZIP перенесены в `Архив/Сборки_локально/` на рабочем ПК. В клоне их можно восстановить из [коммита перед уборкой](https://github.com/kastartorij-dot/kordim/tree/2e3b5fb671906ca9018bd4b118dca69259264318/Игры/Общага/Сборки). Свежие пакеты собираются в `builds/пакеты/`.

- [Материалы передачи от 23.11.2026](Материалы_передачи_2026-11-23/README.md) — утверждённые модели, исходники БЦ «Асгард» и разбор архивных правок.
- [Автопроверки](../Документы/Автопроверки.md) — команды для проверки модели, ссылок и сцены Godot.
