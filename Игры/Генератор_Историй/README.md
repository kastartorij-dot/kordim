# Кордим: Хроники

Версия 06.10.2026. Источник: Index.html (движок и лорбук), chronicles.js (интерфейс партии), ai.js (запросы, память, расходы и изображения), ai-models.js (резервный публичный каталог), chronicles.css и assets/. Переносятся вместе.

## ИИ и модели

Настройки открываются кнопкой «ИИ · модели и расходы». Три независимых выбора: рассказчик, архивариус и изображения. Новые истории получают DeepSeek V4 Pro + Qwen3.8 Flash + Seedream 5.0 Flash. Сохранённые пользователем модели не заменяются автоматически; новый комплект применяется отдельной кнопкой.

«Выбрать» у текста открывает предварительные пять кандидатов по цене и возможностям, затем весь текстовый каталог с поиском. Это не измеренный рейтинг качества русской прозы. «Сравнить текст моделей» отправляет одну сцену выбранным моделям: отдельные платные запросы, ответы не меняют историю. Цены обновляются из OpenRouter; при недоступности сети используется снимок от 06.10.2026. Методика и источники: [AI.md](AI.md).

Режим «Через чат»: игра собирает пакет из канона, героя, текущего состояния, памяти и действия. Игрок копирует его в чат и вставляет ответ. Формат ответа проверяется до применения. API-ключ в пакет не входит. Генерация вариантов героя через API и автоматическое сжатие в этом режиме выключены; том памяти можно составить и исправить вручную. Картины требуют отдельного API-ключа независимо от текстового режима.

## Память

Рассказчик возвращает прозу, четыре действия и JSON текущего состояния. По умолчанию отдельный архивариус после каждого хода извлекает краткую запись журнала и обновления энциклопедии. Он не управляет деньгами, вещами и ранами. Если архивариус не ответил или дал некорректный JSON, сцена сохраняется с понятным сообщением; используются служебные записи самого рассказчика, если они корректны. Автоматического платного повторного запроса нет.

Энциклопедия хранит людей, места, предметы и факты с достоверностью «факт», «слух» или «предположение». Дубликаты объединяются по типу и имени без регистра и ё; разные имена и склонения требуют ручной правки. В запрос попадают свежие и упомянутые записи с ограничением объёма. Журнал сохраняет события и снимки состояния после глав.

После превышения 40 сообщений архивариус сжимает старую часть в обновлённый том памяти. Полная проза остаётся в storyArchive для чтения. Неудачное сжатие не удаляет историю. В «Память кампании» можно выбрать диапазон глав, указать важные детали, создать черновик и исправить его перед сохранением. «Что получит рассказчик» показывает отобранную память. Том заменяет покрытые им главы в запросах; текущее действие всегда остаётся.

Энциклопедия, журнал и том входят в снимки состояния. Переписывание, выбор другого варианта и откат меняют память вместе с сюжетом. Расходы хранятся отдельно и не отменяются откатом. Сессия не меняет канон и вики мира. Старые сохранения открываются; утраченный раньше текст восстановить нельзя.

## Портреты и иллюстрации

Генерация только по кнопке. Портрет доступен после выбора персонажа на экране подтверждения и в карточке героя. Промпт строится из окончательных сведений героя и правил визуального мира; его можно исправить. Для сцены используется выбранный вариант ответа. Картинка привязана к этому варианту, а не ко всем его переписываниям.

Выбор моделей картинок показывает цену одной генерации и поддержку референса: Seedream 5.0 Flash, Recraft V4.1 Flash, FLUX.3 Image. Параметры берутся из native Image API. У Seedream можно передать портрет героя в сцену. Для FLUX референс отключён, пока endpoint не публикует его цену. Никакой гарантии одинакового лица между запросами нет.

Изображения хранятся в IndexedDB, отдельно от localStorage с текстом. Они входят в экспорт истории и восстанавливаются при импорте. Если браузер не смог записать картинку, она остаётся в памяти текущей вкладки и доступна для скачивания/экспорта; сообщение предупреждает об этом.

## Расходы и ключ

Ориентир пользователя — до $3 за 100 ходов. Локальный бюджет истории по умолчанию $3, одного запроса — $0.25. Проверка перед запросом приблизительная: русский текст оценивается по символам, стоимость вывода — по лимиту токенов. Она не заменяет лимиты аккаунта OpenRouter. Фактический usage.cost учитывается, если провайдер его прислал; иначе сумма помечается оценочной. Отдельно учитываются рассказчик, журнал, том, сравнения и картинки. При обрыве текстового запроса до получения usage списание может быть неизвестно; проверять Activity OpenRouter.

Модель явно выбранная, скрытой смены модели и автоматического платного ретрая нет. Reasoning отключается у моделей, которые разрешают это; у обязательного reasoning выбирается low. При обрезанном ответе ход не применяется, оплаченный запрос учитывается. Основной лимит вывода для новых настроек — 4000 токенов.

Ключ используется только для запросов OpenRouter. Пользователь решает, запоминать ли его в браузере. По умолчанию экспорт не содержит ключ; отдельная галка явно включает перенос ключа. На статическом сайте ключ виден владельцу браузера: серверного общего ключа нет.

## Проверки и публикация

Запуск через HTTP рекомендуется для хранилища изображений. Другой источник страницы (порт, hostname, file://) имеет другое локальное хранилище. Использовать экспорт/импорт для переноса.

    node tests/session-memory.mjs
    node tests/ai.mjs

Проверки не используют платный API: запросы, поток, JSON, изображения и IndexedDB имитируются. В браузере проверены ручной ход, выбор моделей, цены, карточка выбранного героя и интерфейс памяти. 06.10.2026 с разрешения автора сыграны пять платных ходов и проведено сравнение рассказчиков и извлечения памяти. Результаты и ограничения — [PLAYTEST.md](PLAYTEST.md). Генерация изображений и длинное сжатие памяти реальным API в этом прогоне не проверялись. Предвыбор: DeepSeek V4 Pro для рассказчика, Qwen3.8 Flash для журнала; прежний Flash обновляется один раз, остальные пользовательские модели сохраняются.

Публикация из Игры/Порт/:

    npm run publish-stories
    npm run check

Публичная копия Игры/Сайт/Игра/Истории/ собирается скриптом. Не редактировать её вручную. Исходные иллюстрации: [ART.md](ART.md).
