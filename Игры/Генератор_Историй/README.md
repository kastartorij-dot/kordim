# Кордим: Хроники

Версия 06.10.2026. Index.html — движок и лорбук; chronicles.js — интерфейс и память сессии; chronicles.css — оформление; assets/ — иллюстрации. Эти файлы переносятся вместе.

## Что реализовано

- Меню с обложкой и тремя независимыми историями. Настройки OpenRouter свёрнуты.
- Выбор готового наброска, своего героя или четырёх вариантов от модели. Герои из сохранений доступны для нового старта.
- Экран игры: герой и состояние слева, история в центре, главы справа. Вещи, журнал и указания рассказчику под рукой.
- Энциклопедия партии: люди, места, предметы и факты, поиск, категории, карточки из текста и ручное исправление.
- Журнал показывает события и снимки состояния после ходов.
- Старые главы при сжатии контекста сохраняются для чтения в storyArchive, но повторно в запросы модели не отправляются.
- Кнопка «Посмотреть пример» работает без ключа и запросов, не занимает слот и не сохраняет демонстрационные данные.

## Память сессии

В том же ответе, что и проза, рассказчик возвращает необязательный тег <лор> с JSON-массивом. Пример записи:

    {"kind":"person","name":"Лодочник","description":"Обещал переправу утром.","certainty":"факт"}

Типы: person, place, item, fact. Статусы: факт, слух, предположение. Без корректного статуса запись считается предположением. Пустые и некорректные записи отбрасываются; сломанный тег не мешает чтению основного ответа. За ход применяется до 12 записей; имя ограничено 100 символами, описание — 600, база — 300. Дубликаты объединяются по типу и имени без учёта регистра и ё; разные имена и склонения пока требуют ручной правки.

Память хранится в gameState.sessionLore и входит в снимки для отката и смены вариантов. В промпт попадают свежие и упомянутые записи с бюджетом 4000 символов. Указание рассказчику хранится в gameState.direction. Отдельного платного запроса для извлечения лора нет. Модель может пропустить тег; отсутствие записей не выдаётся за успешное извлечение. Живое соблюдение формата требует прогона с моделью автора.

Сессия не меняет канон и данные вики. Старые сохранения открываются с пустой энциклопедией; ранее утраченные главы восстановить нельзя.

## Запуск и проверки

Открыть Index.html вместе с соседними файлами или раздать папку через HTTP. Настройки и сейвы привязаны к источнику страницы: другой порт, hostname или переход с file:// на HTTP — отдельное хранилище. Для переноса использовать экспорт/импорт.

Проверка памяти без сети и расходов:

    node tests/session-memory.mjs

Публикация из Игры/Порт/:

    npm run publish-stories
    npm run check

Публичная копия в Игры/Сайт/Игра/Истории/ собирается автоматически; руками не правится. Иллюстрации и промпт обложки: [ART.md](ART.md).
