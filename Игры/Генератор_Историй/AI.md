# ИИ для Кордима — решения и источники, 06.10.2026

## Что известно о StoryForge

В пользовательских экранах видны отдельные энциклопедия, журнал, снимки глав и добавление встреченных людей и локаций. В справке сайта описаны библиотекарь и тома памяти. Это достаточный ориентир для разделения ролей и памяти партии. Публичную техническую спецификацию с точными текущими model IDs, промптами и внутренним алгоритмом поиска памяти установить не удалось. Одноимённые GitHub/PyPI-проекты не считаются документацией storyforge.ru без подтверждения связи. Наша схема — собственная адаптация наблюдаемого поведения, не заявление о копировании их серверной реализации.

## Роли

| Роль | Новое значение | Задача |
|---|---|---|
| Рассказчик | deepseek/deepseek-v4-pro | Проза, диалоги, действия, состояние |
| Архивариус | qwen/qwen3.8-flash | Факты и JSON журнала, энциклопедия, сжатие |
| Художник | bytedance-seed/seedream-5-0-flash | По кнопке: выбранный герой или сцена |

Архивариус не меняет инвентарь, раны и деньги. Модель может ошибиться, поэтому факты различают достоверность и доступны для ручной правки. Канон неизменный, сведения сессии отдельные. Полный архив не уничтожается при сжатии.

## Пять текстовых кандидатов

Цены — USD за миллион входных/выходных токенов из публичного API каталога, не фиксированная оферта. Без скидок кэша, reasoning и доплат. Оценка 100 ходов: 16k входа + 2k выхода рассказчика на ход, 3.5k/1.2k архивариуса Qwen; картинки отдельно. Фактическая длина памяти отличается.

| Модель | Вход / выход | 100 ходов по допущению | Причина включения |
|---|---:|---:|---|
| DeepSeek V4 Pro | 0.2088 / 0.4176 | ~0.53 | Дешёвый каталог, большое окно, стартовый баланс |
| Qwen3.8 Flash | 0.15 / 0.47 | ~0.44 | Экономная проза и извлечение фактов |
| GPT-6 Luna | 0.10 / 0.50 | ~0.37 | Недорогой универсальный альтернативный стиль |
| GLM 5 | 0.60 / 1.92 | ~1.45 | Замена недоступного Mistral; кандидат для сравнения, reasoning отключён |
| Gemini 3.1 Flash Lite | 0.25 / 1.50 | ~0.81 | Ещё один недорогой вариант с большим окном |

06.10.2026 проведено короткое практическое сравнение: предвыбор DeepSeek Pro для прозы и Qwen для памяти. [Методика, ответы и ограничения](PLAYTEST.md). Это предварительная подборка; независимый рейтинг русской художественной прозы не измерен. В игре есть сравнение одной сцены выбранными моделями. Оценивать: живые реплики, отсутствие клише, сохранение канона, причинность действий, качество JSON и фактические расходы. Claude Sonnet 5.5 доступен через весь каталог, но при 2/10 за миллион (~$5.5 по тому же сценарию) не входит в стартовую пятёрку для бюджета $3.

DeepSeek: цена живого каталога может отличаться от описания на странице модели и от конкретного провайдера. Запрос ограничивает ставку провайдера относительно цены каталога; если такой маршрут недоступен, показывается ошибка. Смена модели требует явного выбора. У всех моделей цены обновляются при загрузке и по кнопке.

## Можно ли играть через Codex / ChatGPT

Да, вручную: игра выдаёт пакет, игрок отправляет его в чат и возвращает ответ. В игре этот режим уже реализован и не вызывает текстовый API. Автоматический текущий режим использует OpenRouter: ключ создаётся отдельно, платные модели расходуют кредиты; бесплатные модели из каталога имеют свои ограничения. Этот чат не является постоянным сервером запущенного сайта.

По текущей официальной документации OpenAI существует Sign in with ChatGPT с использованием подходящих Plus/Pro-планов в участвующих приложениях; нужны регистрация клиента, OAuth/PKCE, отдельные inference scopes и подходящая доступность. Для выбранных частных клиентов/партнёров и open-source предусмотрены разные условия. Это отдельная интеграция, в этой версии не реализована; обычный OpenRouter-ключ не расходует подписку ChatGPT. Нельзя просто вставить токен Codex в игру.

## Проверено и не проверено

Пройдены tests/session-memory.mjs и tests/ai.mjs, публикационная сверка и ручная проверка браузера. Проверены поток SSE, стоимости usage и оценки, лимиты до отправки, откаты и журнал, неудача архивариуса, сохранение текущего действия после тома, Image API, ссылки на портрет, IndexedDB и экспорт с картинкой. Сетевые платные запросы не отправлялись. Без реального игрового прогона нельзя гарантировать художественный стиль, лица между иллюстрациями и точность извлечения фактов.
