# Материалы для игры

Документы, которые нужны в работе. Статус каждого указан в нём самом: спецификация, черновик, концепт или кандидат. Ничего отсюда не становится каноном или реализацией из-за того, что лежит здесь. Открытые задачи по этим файлам записаны на [доске](../../ДОСКА.md).

| Папка | Что внутри | Состояние |
|---|---|---|
| `История_и_цели/` | Итог шага 1, четыре цели первого сезона, реестр первого сезона, голоса и ветки, цены и календарь, образ Одвина и вступление, сверка Одвина и Бренна | Опора сюжета; на эти файлы ссылаются `Данные/` и `Движок/` |
| `Жители/` | Диалоги 01–34 от других ИИ, кандидаты в жители (Мэсти Вол, Нэра, Марна, Тава), лор для диалогов, реестр жителей `НПС_РЕЕСТР.html`, выгрузка всех диалогов, «Базовый слой разговоров девяти мест» | Диалоги 01–34 в основном внедрены. Мэсти и Нэра в игре нет. «Базовый слой» нужно сверить с игрой |
| `Отношения/` | Каталог 13 типов романтических линий | Сделаны три линии: Фрея, Ния, Тава |
| `Мини_игры_и_мысли/` | Правила и 24 задания «Веса» и «Счёта», девять мыслей, матрица сочетаний | Внедрено; словесные ограничения мыслей не сделаны |
| `Места/` | Проект пяти новых кварталов, кандидаты в люди, реплики первого слоя, каркас сцен, восемь событий ночлежки | Места внедрены; имена семи новых людей не утверждены |
| `Вещи/` | ТЗ одежды и ТЗ предметов и инвентаря | Основа работает, часть сюжетных связей открыта |
| `Работы/` | Снимок текстов работ из игры | Генерируется скриптом |
| `Концепты/` | Концепты дел, девяти мест и диалогов, решения по черновикам ИИ, анализ аналогов игры | Большей частью внедрено; открытые идеи анализа аналогов — на доске |
