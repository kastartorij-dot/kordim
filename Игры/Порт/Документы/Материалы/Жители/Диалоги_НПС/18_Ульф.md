# 18. Ульф — v1
`ulf` · Рынок (торговый), Чёрный ряд, у закрытых лотков · значимый · 4 ветки + `вход`
Условие появления в игре: `{отрезок:'ночь'}`.

Формат записи — как в пачке 1; правила пачки 4 — в `00_пачка4_общее.md`.
Бюджет рынка — 6 ходов: максимум 5 новых одноходовых веток. «Ходы» в таблицах — только разговоры.

## Карточка

- **Голос:** скупой на слова, наблюдательный; светит фонарём на лица; предупреждает, что ночью вслух не торгуются. «Ты».
- **Опора:** кто пришёл после закрытия, ночные порядки, видимость, осторожность.
- **Не вводим:** связь с контрабандой, собственный товар, хозяина ряда, прошлое. Он сторож, не торговец.
- ⟦пр⟧ = новая деталь; замена — в `00_пачка4_общее.md`.

## Вход и «видят»

Резерв: `вступление` — «Ульф поднимает фонарь, чтобы ты видел его лицо, а он — твоё»; `снова` — «Ульф у закрытых лотков. Фонарь он держит ниже, чем в первый раз».

### Ветка `вход` — ходы 0, засчитывать: нет
**`старт`**
- Т `[нетФакта знакомы]`: Ульф поднимает фонарь, чтобы ты видел его лицо, а он — твоё.
- Т `[факт знакомы]`: Ульф у закрытых лотков. Фонарь держит ниже, чем в первый раз.
- Т `[факт ульф_знает_зачем]`: — Опять по делу? Как говорил. Свет там же.
- при: `{факт:'знакомы'}`
- Т: `видят`
- Выбор `подойти` — Подойти ближе. → хаб
- Выбор `уйти` (закреплён) — «Пойду.» → закрыть, исход `false`

**`видят`** (только текст)
- `цел [0,1]`: — Хромаешь, — говорит он. — Иди по свету, там ровно.
- `тепло [0,1]`: — Ночью зябко, — замечает он. — Не стой на месте.

### `фонарь` — «Свет в лицо»
Вход: «Я пришёл.» · Доступ: — · Ходы 1 · Знание: —
Повторяемая: все выходы `исход false`.

**`старт`**
- Т: Ульф держит фонарь так, что свет бьёт в глаза. — Скажи, зачем пришёл.
- Выбор `зачем` — «Ищу сведения. Не знаю, у кого спросить.» · если `{нетФакта:'ульф_знает_зачем'}` · эфф: `{распол:{ulf:1}, факт:'ульф_знает_зачем'}` → `зачем`
- Выбор `просто` — «Просто смотрю.» → `просто`
- Выбор `опусти` — «Опусти фонарь, пожалуйста.» → `опусти`
- Выбор `уйти` (закреплён) — «Пойду.» → закрыть, исход `false`

**`зачем`**
- Т: — Ночью не спрашивают. Утром спроси у торговцев. Здесь смотри и уходи по свету.
- Выбор `ясно` — Кивнуть. → хаб, исход `false`

**`просто`**
- Т: — Смотри. Руками закрытое не трогай.
- Выбор `ясно` — Кивнуть. → хаб, исход `false`

**`опусти`**
- Т: Он опускает фонарь на ладонь. — Лицо видно. Больше не надо.
- Выбор `ясно` — Кивнуть. → хаб, исход `false`

## Проверка беседы

| Сценарий | Результат |
|---|---|
| Первый разговор | `фонарь`, `правила`; остальные скрыты. |
| Возвращение | `снова`: фонарь ниже. |
| Ранний выход | `уйти` с `исход false`; `фонарь` остаётся доступным. |
| Полный выход | `пройдена`; повтор — `Уже`, 0 ходов. |
| Повтор завершённой ветки | `Уже`, хаб. |
| Недостаток ходов | При 1 оставшемся ходе новая ветка недоступна. |
| Нет знания | Знание не требуется. |
| Получение знания без поздней награды | Знание не выдаётся. |
| Повтор после награды | `зачем` скрыт (`нетФакта`); остальные ответы повторимы без награды. |
