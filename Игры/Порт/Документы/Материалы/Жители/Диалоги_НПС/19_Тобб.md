## Карточка

- **Голос:** канцелярская точность, осторожность с именами и формулировками; не торопится говорить то, что может оказаться записанным. «Вы» — обращается к герою на «вы»; герой отвечает «вы».
- **Опора:** пошлины, книги, квитанции, порядок оформления, различие между записью и передачей денег, будни Совета.
- **Не вводим:** личное участие в истории Бренна, готовность раскрыть тайну близнецов, суммы платежей. Не глава Ножей (по решению автора он представляет их в Совете, но сам этого не заявляет).
- ⟦пр⟧ = новая деталь; замена — в `00_пачка4_общее.md`.

## Проверка беседы

| Сценарий | Результат |
|---|---|
| Первый разговор | Доступны `знакомство`, `платёж`; остальные скрыты. |
| Возвращение | `снова`; при `тобб_порядок` — строка про порядок. |
| Ранний выход | `уйти` с `исход false`. |
| Полный выход | `пройдена` у `платёж`, `запрос`, `совет`, `дорры`. |
| Повтор завершённой | `Уже`, 0 ходов, хаб. |
| Недостаток ходов | Остаётся последний ход — новая ветка недоступна; бюджет места не известен. |
| Нет знания | `дорры` скрыта без темы `dorry_dvoe`. |
| Получение знания без поздней награды | Знание не выдаётся; награда только за `порядок`. |
| Повтор после награды | `порядок` скрыт (`нетФакта`). |
