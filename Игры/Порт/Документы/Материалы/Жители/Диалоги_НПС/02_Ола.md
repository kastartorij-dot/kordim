# 2. Ола — v2
`ola` · Синий час, Лестница и коридор · значимый · основные ветки 5 + отказ 0 ходов + 1 открываемая

## Карточка

- **Речь:** быстро, увлечённо, любит бытовые подробности и систему (нитки, порядок стирки). Говорит гостю «вы». Может проболтаться, потом закрыться; при нажиме уходит по делам — решает сама.
- **Компетентна:** знает бельё, расписание, где что лежит; поправляет гостя по делу, не извиняясь.
- **Настроение меняется:** азарт (о работе) → смущение (о себе) → осторожность (о хозяйке) → твёрдость («про это нет»).
- **Лор по справке:** год без долгов; копила на ласточку; боится хозяйку, тепло о Сибе. Не вводим: действующий долг, знание расчётов Ярны, возраст.
- ⚑ Предложения автору (бытовые детали, не лор): синяя нитка на простынях, «гуляющая» третья ступенька, вышивка «дом на всю жизнь», распорядок стирки. Сванна (резерв места, не подключена к комнатам) в этой версии не упоминается — просто для простоты.

## Вход, приветствия, «видят»

Резерв: `вступление` — Ола прижимает к себе стопку белья и улыбается: быстро, на всякий случай. `снова` — Ола на лестнице с новой стопкой, узнаёт тебя по шагу.

## Расположение: маршруты

| Маршрут | Итог |
|---|---|
| **Помощь.** V1: `знакомство`→`помочь` (+1), Ола сама заканчивает разговор. V2: `сиб`→`слово` (+1) | 2 → открыты `цветок_отказ`, `год_без_долга` |
| **Сразу отойти.** V1: `знакомство`→`уйти`. V2: `про_работу`→`помочь` (+1) | 1; не заперто |
| **Монета.** V1: `монета` (0 к расположению, деньги по явному `стоит`) | 0; дальше `про_работу`→`помочь` |
| **Нажим.** V2: `цветок_отказ`→`давить` (нужно доверие 2) | тема закрыта до конца визита; расположение не меняется |

Награда `помог_оле` один раз: условие `нетФакта:'помог_оле'` стоит в **обоих** местах помощи; `ола_слово` — в обоих вариантах обещания.
