# 20. Рест Дорр — v1
`rest_dorr` · Контора Дорров (доки), кабинет смотрителя, за столом · ключевой · 5 веток + `вход` + `выход`

Формат записи — как в пачке 1; правила пачки 4 — в `00_пачка4_общее.md`.
Бюджет конторы в присланных материалах не указан — проверить в `новые-места.js`. «Ходы» в таблицах — только разговоры; вход в кабинет, платёж и сюжетные дела в них не учтены.

## Карточка

- **Голос:** хозяин конторы; требует изложить дело коротко; контролирует, о чём идёт разговор; говорит о полномочиях и расчёте, а не о чувствах. «Ты».
- **Позиция:** смотритель доков; по канону внешне неотличим от брата-близнеца Кейна; Рест — публичное лицо Мокрых ножей и официальный старший смотритель доков. Корабли платят официальную пошлину и неофициальную Доррам.
- **Тайна второго Дорра:** значимое знание с последствиями. Рест не подтверждает и не опровергает её; два стула и подпись сами по себе близнеца не доказывают.
- **Бренн:** осторожный разговор; единственная фраза о нём — существующая («Бренн умел считать. Этого у него не отнимали»). Печать в книге Бренна и виновник его бед не называются.
- **Не вводим:** семейные детали, прошлое, мотивы близнецов, устройство власти Дорров.
- ⟦пр⟧ = новая деталь; замена — в `00_пачка4_общее.md`.

## Вход

Резерв: `вступление` — «Дорр смотрит на тебя поверх книги, не поднимаясь со стула»; `снова` — «Дорр за столом. Книга открыта на той же странице».

### Ветка `вход` — ходы 0, засчитывать: нет
**`старт`**
- Т `[нетФакта знакомы]`: Дорр смотрит на тебя поверх книги, не поднимаясь со стула.
- Т `[факт знакомы]`: Дорр за столом. Книга открыта на той же странице, закладка на месте.
- Т `[факт дорр_знает_сына]`: — Скарре. Садись.
- Т `[флаг дорр_двое_закрыт]`: — Про это достаточно.
- при: `{факт:'знакомы'}`
- Выбор `сесть` — Сесть. → хаб
- Выбор `уйти` (закреплён) — «Не буду отнимать время.» → ветка `выход`

### `выход` — прощание
Вызов: выбор `уйти` из `вход` → ветка `выход`. При уходе через дверь кабинета нужен тот же вызов (задача внедрения). Ходы 0, засчитывать: нет.

**`старт`**
- Т `[факт дорр_знает_сына]`: — Скарре. Дверь там.
- Т `[факт дорр_коротко, доверие 1]`: — В следующий раз тоже коротко.
- Т `[доверияДо 1]`: — Дверь там.
- Выбор `выйти` (закреплён) — Выйти. → закрыть

## Проверка беседы

| Сценарий | Результат |
|---|---|
| Первый разговор | `дело`, `пошлина`; `бренн` — после `коротко` (доверие 1) с первого посещения. |
| Возвращение | `снова`; при `дорр_знает_сына` — «Скарре. Садись.» |
| Ранний выход | `уйти` → `выход`; ветки с `исход false` остаются доступными. |
| Полный выход | `пройдена` у `пошлина`, `бренн` (после `отец`/`почему`), `ножи`; повтор — `Уже`. |
| Повтор завершённой | `Уже`, 0 ходов, хаб. |
| Недостаток ходов | При одном оставшемся ходе новая ветка недоступна; бюджет места не известен. |
| Нет нужного знания | `двое` скрыта без темы `dorry_dvoe`. |
| Получение знания без поздней награды | Знание не выдаётся; в `двое` награды нет. |
| Повтор после награды | `коротко` скрыт (`нетФакта`); остальные ответы повторимы без награды. |
