# Промты для генерации изображений «Порта Теней»

Только визуальные материалы: каждый промт можно копировать отдельно. Везде задан единый сдержанный пиксельный стиль. Для портретов и новых сцен использовать утверждённые изображения как референсы, если они есть. Кандидатский арт не считать автоматически частью игры; часовню и крест не менять.

## Общие ограничения

- В промтах в квадратных скобках заменить только предметы, состояния и детали, которые уже утверждены для игры.
- Просить генератор не рисовать точные надписи: имена, суммы и текст поверх бумаги лучше добавить средствами игры.
- Для наборов иконок проверить, что каждый элемент можно обрезать отдельно и он читается в маленьком размере.
- Если изображение должно продолжать существующий арт, прикладывать его как референс и просить сохранить композицию и узнаваемые детали.
- Перед подключением проверить кадрирование на телефоне и сверить файл с `Документы/АРТ_РЕЕСТР.md`.
