# Документы «Порта Теней»

Что делать дальше — в [доске](../ДОСКА.md). Здесь только опоры для работы. С 28.10.2026 документов меньше: отработанное лежит в архиве, нужное для игры — в «Материалах».

| Где | Что лежит |
|---|---|
| [Порт_ГДД.md](Порт_ГДД.md) | Что строим: рамка игры и решения автора |
| [ПЛАН_ДОРАБОТКИ.md](ПЛАН_ДОРАБОТКИ.md) | Полные требования 17 шагов и раздел «Готово» у каждого; таблица «Конечный объём» в начале. Справочник, задачи ведутся на доске |
| [ПОРЯДОК_РАБОТЫ_И_ВЕРСИЯ.md](ПОРЯДОК_РАБОТЫ_И_ВЕРСИЯ.md) | Синхронизация, сборка, проверки, публикация |
| [Прогоны](Прогоны/README.md) | Отчёты игры и [реестр замечаний](Прогоны/РЕЕСТР.md) с ID и критериями |
| [Материалы](Материалы/README.md) | Сценарные спецификации, диалоги жителей, концепты, задания мини-игр. На часть из них ссылаются код, скрипты и тесты |
| [Арт](Арт/) и [арт-реестр](АРТ_РЕЕСТР.md) | Промты, задания на подключение картинок, статус изображений |
| [На_Разбор](На_Разбор/README.md) | Входящая папка автора |
| [Архив](Архив/README.md) | Отчёты приёмок, пачки, патчи и zip, журнал, старые планы и аудиты. Не правится |

Выгрузка диалогов `Материалы/Жители/ВСЕ_ДИАЛОГИ_НПС.md` собирается `Скрипты/собрать-диалоги.mjs`. Тексты работ `Материалы/Работы/Шаг_5_тексты_игры.md` собирает `Тесты/тексты-работ-в-md.mjs`, тест шага 5 сверяет их с игрой. Результаты сквозных партий и приёмки шага 11 тесты пишут в `Тесты/Результаты/`.

Наличие документа означает наличие материала. «Принято» означает согласованное решение, «в игре» — реализацию, «проверено» — пройденные сценарии. Перенос файла не меняет его статуса и не делает предложение каноном. Где какой файл был до 28.10 — в [описи переноса](Архив/ОПИСЬ_ПЕРЕНОСА_28_10_2026.json).
