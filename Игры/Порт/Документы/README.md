# Документы игры «Порт Теней»

Начните с [ГДД](Порт_ГДД.md) и [плана полной игры](ПЛАН_ДОРАБОТКИ.md).
[План в 17 шагах](Разработка/ПЛАН_17_ШАГОВ.md) объясняет тот же объём проще.
Фактическое состояние игры сверяйте с кодом и [журналом](Порт-журнал.md):
планы и черновики сами по себе не означают внедрение.

| Раздел | Что внутри |
|---|---|
| [Разработка](Разработка/) | план в 17 шагах и отчёты о выполненных шагах в `Состояние/` |
| [Мир](Мир/) | новые районы и кандидаты в НПС; предложения для игры, не мастер-канон |
| [Арт](Арт/) | промты и материалы для изображений; статус активов в [арт-реестре](АРТ_РЕЕСТР.md) |
| [Материалы ИИ](Материалы_ИИ/) | исходные концепты, задания, результаты и материалы на разбор |
| [Архив](Архив/) | ранние концепты, завершённые задания этапов 2–5 и пакеты кода |

## Опорные файлы в корне

- [ГДД](Порт_ГДД.md) — утверждённые игровые решения.
- [План полной игры](ПЛАН_ДОРАБОТКИ.md) и [реестр внедрения материалов ИИ](РЕЕСТР_ВНЕДРЕНИЯ_МАТЕРИАЛОВ_ИИ.md) — что ещё предстоит сделать и откуда брать материал.
- [Журнал](Порт-журнал.md) — хронология решений и проверок.
- [Аудит материалов ИИ](АУДИТ_МАТЕРИАЛОВ_ИИ.md) — оценка источников; [решения по черновикам](Материалы_ИИ/Задания_И_Результаты/РЕШЕНИЯ_ПО_ЧЕРНОВИКАМ_ИИ.md) — принятые правила.
- [Реестр НПС](НПС_РЕЕСТР.html) и `нпс-реестр-данные.js` — интерактивный справочник и его данные.
- `лор-для-диалогов.js` и [выгрузка всех диалогов](ВСЕ_ДИАЛОГИ_НПС.md) — рабочие файлы генератора `Скрипты/собрать-диалоги.mjs`; выгрузку править через исходные данные и скрипт.

## Статус папок

- `Материалы_ИИ/Источники/` — предложения других моделей, их сверяют с ГДД и каноном до принятия.
- `Материалы_ИИ/Задания_И_Результаты/На_Разбор/` — полученные материалы, которые ещё требуют редакторского разбора. Имя папки указывает на статус, а не на качество.
- `Архив/Пакеты_Кода/` — старые patch и zip для истории переноса; текущий код находится в `Движок/`, `Данные/` и `Сцены/` проекта.
- `Архив/Версии/` — заменённые редакции. Девять мыслей для шага 17 имеют [уточнённую версию](Материалы_ИИ/Задания_И_Результаты/Шаг_17/Девять_новых_мыслей.md); прежний вариант сохранён в архиве.

В архиве файлы сохранены, чтобы можно было восстановить происхождение решений.
Три побайтно одинаковые копии удалены из входящей папки: `ВСЕ_ДИАЛОГИ_НПС.md`,
`лор-для-диалогов.js`, `Пачка_1_проверка_и_промпт.md`. Их действующие экземпляры
указаны выше и в разделе материалов ИИ.
