# Документы «Порта Теней»

Оба плана используют одинаковые 17 шагов: [упрощённый](Разработка/ПЛАН_17_ШАГОВ.md) объясняет работу, [подробный](ПЛАН_ДОРАБОТКИ.md) содержит требования и приёмку. Для конкретной задачи открывайте нужный шаг, а в больших документах — соответствующий раздел.

| Где | Что лежит |
|---|---|
| [Разработка](Разработка/README.md) | 17 папок: задания, материалы, решения и отчёты по каждому шагу |
| [На_Разбор](На_Разбор/README.md) | Входящие ответы других ИИ, ещё не разобранные и не принятые |
| [Общие_Материалы](Общие_Материалы/README.md) | Концепты и решения, затрагивающие несколько шагов; ссылки вместо копий |
| [Арт](Арт/) | Общие задания на изображения; статус активов в [арт-реестре](АРТ_РЕЕСТР.md) |
| [Архив](Архив/README.md) | Заменённые версии, ранние концепты, старые задания и пакеты кода |

Общие опоры: [ГДД](Порт_ГДД.md), [реестр внедрения](РЕЕСТР_ВНЕДРЕНИЯ_МАТЕРИАЛОВ_ИИ.md), [журнал](Порт-журнал.md), [порядок работы](ПОРЯДОК_РАБОТЫ_И_ВЕРСИЯ.md). [Аудит](АУДИТ_МАТЕРИАЛОВ_ИИ.md) описывает проверки исходников на свою дату и не заменяет текущий код.

[Реестр жителей](Разработка/Шаг_10_Жители_и_разговоры/НПС_РЕЕСТР.html), его данные, редакторский лор и выгрузка диалогов лежат в шаге 10. Выгрузка собирается `Скрипты/собрать-диалоги.mjs`; тексты работ в шаге 5 — `Тесты/тексты-работ-в-md.mjs`.

Наличие документа означает наличие материала. «Принято» означает согласованное решение; «в игре» — реализацию; «проверено» — пройденные сценарии. Перенос файлов между папками не меняет их статуса и не делает предложения каноном. [Старые номера](Разработка/СООТВЕТСТВИЕ_СТАРЫХ_НОМЕРОВ.md) сохранены для чтения истории.
