# Команда ПОРТа

**Одна цель:** довести первый сезон ПОРТа до играбельного и цельного состояния: визуал, механики, история, диалоги, интерфейс, звук. Второй сезон — только после идеального первого. Система работает с 28.10.2026.

## Коротко для автора

- Ты общаешься с одним чатом — **Шефом**. Он закреплён в группе «Порт».
- Шеф сам открывает чаты агентов, раздаёт им работу, проверяет, сливает и выкладывает на сайт.
- К тебе Шеф приходит только с решениями: стиль, сюжетные повороты, новые факты мира, вычитка важных текстов (финалы, личные линии, новое о мире), деньги и аккаунты.
- После каждого круга — отчёт на 5 строк и не больше трёх вопросов.
- Все задачи и решения — в [ДОСКЕ](../../ДОСКА.md). Отработанное убирается в архив, ничего не теряется.

## Круг работы

1. **Сбор.** Шеф читает доску, реестр замечаний и последний отчёт Игрока.
2. **План круга.** До трёх пачек работы. Пачка — одна зона и 10–20 связанных пунктов с понятным признаком «готово». Пачки не трогают одни и те же файлы.
3. **Работа.** Каждый агент — в своём чате и своей копии репозитория (git worktree, своя ветка). Шеф тем временем собирает вопросы к автору.
4. **Приёмка.** Шеф смотрит изменения, гоняет тесты, отдаёт видимое (экраны, тексты, картинки) Критику. Принятое сливает в `main`, собирает сайт, проверяет, отправляет.
5. **Проверка игрой.** Игрок проходит изменённые места и пишет новые замечания.
6. **Отчёт.** Шеф отмечает сделанное на доске и пишет автору: что сделано, что сломалось, что решить.

Ночью круг может идти по расписанию, если автор оставил пачки заранее. Решения, которые Шеф принял за автора, попадают в раздел доски «Решено за автора» на пересмотр.

## Правила

**Игра важнее бумаг.** Новых документов не заводить. Отчёт агента — сообщение коммита и его последний ответ, Шеф переносит итог строкой на доску. Исключения: отчёт прогона Игрока и материалы для игры, на которые ссылается код.

**Один владелец общего.** Только Шеф сливает в `main`, запускает `npm run publish-all`, делает push, правит доску, реестр замечаний и этот файл. Агент коммитит только в своей ветке, не пушит и не собирает копию сайта.

**Свои файлы.** У каждой роли своя зона (в описании роли). Если пачке нужен чужой файл, Шеф ставит её одну или следит, чтобы в круге его не трогал никто другой.

**Канон.** Новые факты мира — только с «да» автора. Перед сдачей текстов — `node Канон/_Сборка/validate.mjs` и сверка с мастер-каноном по фактам, которые затронуты. Тексты помечаются как набросок; важные идут автору на вычитку.

**Проверка по риску.** Сохранения, время, деньги, сроки — обязательный тест и прогон всех `Тесты/*.mjs`. Тексты, цвета, раскладка — проверка глазами в браузере и Критиком. Найденная ошибка, которую можно поймать проверкой, становится проверкой.

**Никто не оценивает свою работу сам.** Видимый результат смотрит Критик или Игрок.

**Не больше трёх агентов одновременно.** Работа идёт большими пачками: запуск агента дорог, размер пачки почти ничего не стоит.

**Модели.** Агенты — Opus, уровень мышления High. Extra High — для баланса, сохранений и ключевых сцен. Haiku к игре не подпускать.

**Нельзя без автора:** платные сервисы, регистрация в сервисах, публикация где-либо кроме нашего сайта, удаление (только перенос в архив), force push, `reset --hard`, `stash` и `pull --autostash`. Последние четыре дополнительно блокирует предохранитель `.claude/hooks/guard.mjs`.

**Память компьютера.** 16 ГБ оперативки. ComfyUI запускать только на время генерации и выключать после, генерации — по одной.

## Инструменты

- **Игра локально:** конфиг `Сайт-Python` в корневом `.claude/launch.json`, адрес `http://localhost:8791/Игра/Порт/`.
- **Проверки:** `Тесты/*.mjs`, затем `npm run publish-all` и `npm run check` (это только Шеф).
- **Браузер:** встроенный браузер приложения, а для ночной игры без открытого окна — плагин playwright.
- **Картинки:** ComfyUI в `D:\AI\ComfyUI` (Z-Image Turbo — генерация, FLUX.2 Klein — правка по образцу), связка `comfyui` для Claude. Наработки по стилю — `Документы/Арт/Стиль_28_10/`.
- **Интерфейс:** плагины frontend-design и playground (страницы с ползунками для настройки баланса и палитры).
- **Скилы автора роликов:** studioigor, ref2game (правила стиля, генерация по частям), gauntlet-loop (доводка одной вещи до эталона).
- **Звук:** ffmpeg (громкость, нарезка). Бесплатные звуки Freesound и Stable Audio Open — после того как автор заведёт бесплатные аккаунты.
