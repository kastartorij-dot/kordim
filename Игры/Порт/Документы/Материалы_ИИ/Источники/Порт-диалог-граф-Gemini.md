### 1. Оценка текущей диалоговой системы
Что работает хорошо:
 * Чёткое разделение данных и движка: Реплики, условия и эффекты лежат в Данные/Места/, движок Движок/разговор.js не содержит захардкоженных имён персонажей.
 * Темы как валюта: Механика владения темами, их достоверности (слышал, подтверждено, опровергнуто), ценности (0–3) и утечек ушам фракций заложена отлично.
 * Память дома: Учёт того, что уже было спрошено, защита от бесконечного фарма расположения и сохранение отношений между визитами работают стабильно.
Главные проблемы текущей модели:
 * Ощущение «банкомата / опросника»: Диалог выглядит не как живая беседа, а как меню терминала. Игрок подходит к NPC и нажимает на темы из списка, получая изолированные абзацы текста.
 * Формализм трёх тонов («прямо / мягко / деньгами»): Переключатель тона часто искусственен. Вместо выбора содержательного действия игрок механически перебирает, какой тон «заходит» данному NPC.
 * Отсутствие истории в кадре (стирание контекста): Каждая новая реплика затирает предыдущую в поле #say. Игрок не видит развития мысли, пикировки и нити разговора.
 * Отсутствие внутренней рефлексии персонажа: В Disco Elysium половина магии диалога — это внутренние комментарии, сомнения, телесные ощущения и профессиональная деформация героя. В «Порте» Одвин пока глух внутри: есть только внешняя реплика NPC и выбор темы.
 * Безопасность и отсутствие риска: За редким исключением (уши таверны, сдача ножа) в диалоге нет напряжения момента, риска ляпнуть лишнее или необходимости бросить кости на проверку самообладания.
### 2. Концепт диалоговой системы в стиле Disco Elysium
#### А. Интерфейс: «Лента диалога» (Dialogue Ledger)
 * Вертикальный свиток вместо одиночной плашки: Полноценная лента сообщений справа (или по центру на мобильных), которая скроллится вверх. Игрок видит историю текущей беседы от входа до финала.
 * Типографика и цветовое кодирование сообщений:
   * Реплики NPC: Жирный шрифт имени, прямая речь в кавычках.
   * Нарратив и окружение: Курсив или приглушённый тон (жесты, скрип половиц, взгляд собеседника).
   * Внутренний голос / тело: Отдельные врезки со специфическим цветом (см. пункт Б).
   * Выборы игрока: Пронумерованный список [1], [2], [3], [4] внизу ленты.
 * Адаптивность под 375px (телефон): Портрет собеседника уменьшается или уходит в шапку/сворачивается, освобождая экран под чтение текста и крупные плашки ответов.
#### Б. «Голоса» Кордима: Телесность и Ремесло вместо навыков Дюбуа
В мире Кордима нет магии и шизофренических голосов, но есть реалистичные факторы, которые комментируют происходящее прямо посреди диалога:
 * Тело (голод, усталость, холод, боль):
   * Сыт 0–1: «Желудок скручивает спазмом. От запаха копчёной рыбы за стойкой кружится голова, ты теряешь мысль собеседника.»
   * Холод / Дрожь: «Пальцы одеревенели. Ты не сможешь быстро вытащить нож, если он полезет под прилавок.»
 * Профессиональное чутьё (ремесло Одвина):
   * Глаз грузчика: Оценивает баланс тела, скрытый под одеждой груз, физическую силу («По тому, как он переносит вес на правую ногу, видно: за голенищем сапога что-то тяжёлое»).
   * Грамота и счёт: Замечает юридические и финансовые оговорки, фальшивые расписки, цену вещей.
   * Игла наколочника: Читает историю по шрамам и чернилам на коже собеседника.
 * Уличное чутьё / Тень:
   * Предупреждает о ловушках, чужих ушах и изменении взгляда («Человек с одной кружкой в углу перестал делать вид, что пьёт. Он слушает»).
#### В. Механика проверок (Skill Checks)
 * Пассивные проверки: Срабатывают автоматически прямо в тексте (показывают скрытую деталь, если соответствующий показатель достаточно высок или при себе есть нужная улика/знание).
 * Активные проверки (Белые и Красные):
   * Белые проверки (White Checks): Можно предпринять попытку с шансом на успех. В случае неудачи вариант временно блокируется, пока игрок не изменит контекст (согреется, поест, поднимет репутацию, узнает новую подтверждённую тему).
   * Красные проверки (Red Checks): Однократный судьбоносный риск (блеф, нажим на авторитета, кража со стойки). Провал навсегда меняет отношение, закрывает ветку или ведёт к насилию/выдворению.
   * Формула шанса: Базовый генератор случайных чисел случай.js (зерно S.мир.сид) + модификаторы от физического состояния (усталость дает минус, сытость и уверенность — плюс), ремесла и отношений.
#### Г. Отказ от жестких трёх тонов к драматическим деревьям
 * Вместо трех абстрактных кнопок прямо / мягко / деньгами формируется набор ситуативных реплик:
   * Вопрос по сути (использование известной темы).
   * Реакция на только что сказанное (сомнение, провокация, уточнение).
   * Физическое действие (положить монету на стол, отвести взгляд, сделать глоток, осмотреть руки).
   * Молчание / отступление.
### 3. Вопросы для уточнения концепта
Перед проектированием архитектуры и переписыванием диалоговых узлов нужно зафиксировать:
 * Отображение шансов проверок: Показываем ли игроку открытые проценты вероятности (например, «[Грамота 65%] Указать на ошибку в расписке») или держим сложность скрытой/описательной («[Сложно]...» / без цифр)?
 * Внутренние реплики (вставки ощущений): Хотите ли вы, чтобы они возникали регулярно во всех локациях (как полноценный нарративный слой диалога), или использовались экономно — только в ключевых моментах и при критических состояниях тела (ранен, замерз, голоден)?
 * Рамки пилота: С какого персонажа и места начнем переработку? Логичнее всего взять Сиба у дверей или Хозяина портовой таверны, полностью пересобрав их под новую механику перед масштабированием на остальные локации.

## 1. Файл Игры/Генератор_Историй/Игры/Порт/Движок/диалог-граф.js

Создайте этот файл в папке Движок/. Он отвечает за расчет шансов, броски, прокрутку ленты и хранение истории:

```js
import { бросок } from './случай.js';

// Зажатие числа в диапазоне
const clamp = (min, max, v) => Math.max(min, Math.min(max, v));

/**
 * Инициализирует диалог с персонажем
 */
export function начатьДиалогГрафа(S, графДиалога) {
  S.сцена.диалогГраф = графДиалога.id;
  S.сцена.текущийУзел = графДиалога.стартовыйУзел;
  S.сцена.лента = []; // История сообщений текущего диалога
  
  // Добавляем стартовый узел в ленту
  перейтиКУзлу(S, графДиалога, графДиалога.стартовыйУзел);
}

/**
 * Переход к новому узлу графа и добавление записей в ленту
 */
export function перейтиКУзлу(S, графДиалога, узелId) {
  const узел = графДиалога.узлы[узелId];
  if (!узел) return;

  S.сцена.текущийУзел = узелId;

  // 1. Пассивные врезки (тело, ремесло, инстинкты)
  if (узел.врезки && узел.врезки.length) {
    for (const в of узел.врезки) {
      if (!в.условие || в.условие(S)) {
        S.сцена.лента.push({
          вид: 'врезка',
          голос: в.голос,
          текст: в.текст
        });
      }
    }
  }

  // 2. Основная реплика NPC
  if (узел.текст) {
    S.сцена.лента.push({
      вид: 'реплика_нпс',
      кто: графДиалога.персонаж,
      текст: typeof узел.текст === 'function' ? узел.текст(S) : узел.текст
    });
  }
}

/**
 * Расчет шанса активной проверки в процентах (0–100%)
 */
export function рассчитатьШанс(S, выбор) {
  if (!выбор.проверка) return 100;
  
  let шанс = выбор.проверка.базовыйШанс || 50;

  // Модификаторы ремесла
  if (выбор.проверка.навык && S.герой.ремёсла?.[выбор.проверка.навык]) {
    const ремесло = S.герой.ремёсла[выбор.проверка.навык];
    if (ремесло.ступень === 'умеешь') шанс += 20;
    if (ремесло.ступень === 'набил руку') шанс += 35;
    if (ремесло.ступень === 'мастер') шанс += 50;
  }

  // Модификаторы физического состояния
  if (S.герой.тело.сыт <= 1) шанс -= 15;
  if (S.герой.тело.отдых <= 1) шанс -= 15;
  if (S.герой.тело.тепло <= 1) шанс -= 15;
  if (S.герой.тело.цел <= 1) шанс -= 10;

  // Дополнительные условия проверки
  if (выбор.проверка.бонус && typeof выбор.проверка.бонус === 'function') {
    шанс += выбор.проверка.бонус(S);
  }

  return clamp(5, 95, Math.round(шанс));
}

/**
 * Выбор варианта ответа игроком
 */
export function сделатьВыборГрафа(S, графДиалога, индексВыбора) {
  const узел = графДиалога.узлы[S.сцена.текущийУзел];
  const доступные = получитьДоступныеВыборы(S, графДиалога);
  const выбор = доступные[индексВыбора];
  
  if (!выбор) return;

  // Запись реплики игрока в ленту
  S.сцена.лента.push({
    вид: 'реплика_игрока',
    текст: выбор.текст
  });

  // Если это проверка навыка (Белая или Красная)
  if (выбор.проверка) {
    const шанс = рассчитатьШанс(S, выбор);
    const рулетка = Math.floor(бросок(S) * 100);
    const успех = рулетка < шанс;
    
    // Запоминаем статус проверки в памяти мира
    S.мир.проверки ??= {};
    const чекId = `${графДиалога.id}:${выбор.ид}`;

    S.сцена.лента.push({
      вид: 'результат_проверки',
      успех,
      текст: `${выбор.проверка.название}: ${успех ? 'УСПЕХ' : 'ПРОВАЛ'} (Шанс: ${шанс}%)`
    });

    if (успех) {
      S.мир.проверки[чекId] = 'успех';
      if (выбор.приУспехе.действие) выбор.приУспехе.действие(S);
      перейтиКУзлу(S, графДиалога, выбор.приУспехе.следУзел);
    } else {
      S.мир.проверки[чекId] = выбор.проверка.тип === 'красная' ? 'заблокирован' : 'провал';
      if (выбор.приПровале.действие) выбор.приПровале.действие(S);
      перейтиКУзлу(S, графДиалога, выбор.приПровале.следУзел);
    }
    return;
  }

  // Обычное действие
  if (выбор.действие) выбор.действие(S);
  if (выбор.следУзел) перейтиКУзлу(S, графДиалога, выбор.следУзел);
}

/**
 * Формирует список вариантов ответа для текущего шага
 */
export function получитьДоступныеВыборы(S, графДиалога) {
  const узел = графДиалога.узлы[S.сцена.текущийУзел];
  if (!узел || !узел.выборы) return [];

  return узел.выборы.filter(в => {
    // 1. Проверка общего условия видимости
    if (в.условие && !в.условие(S)) return false;

    // 2. Проверка заблокированных проверок
    if (в.проверка) {
      const чекId = `${графДиалога.id}:${в.ид}`;
      const статус = S.мир.проверки?.[чекId];
      if (статус === 'заблокирован' || статус === 'успех') return false;
      if (статус === 'провал' && в.проверка.тип === 'белая') {
        // Белая проверка закрыта, пока не сработает условие сброса
        if (в.проверка.сброс && в.проверка.сброс(S)) {
          delete S.мир.проверки[чекId]; // Сброс замка
          return true;
        }
        return false;
      }
    }
    return true;
  });
}
```

## 4. Как это связать в интерфейсе (экраны-места.js)

Когда в текущей сцене активен `S.сцена.диалогГраф`, рендер реплики и кнопок действий заменяется лентой и выборами из графа:

```js
// Внутри рендера реплики и действий:
if (S.сцена.диалогГраф) {
  const граф = ДИАЛОГ_СИБ_ВХОД; // Либо импорт из реестра диалогов
  const лентаHtml = S.сцена.лента.map(сообщение => {
    if (сообщение.вид === 'реплика_нпс') {
      return `<div class="dl-item dl-npc"><b>${сообщение.кто}</b>${сообщение.текст}</div>`;
    }
    if (сообщение.вид === 'реплика_игрока') {
      return `<div class="dl-item dl-player">— ${сообщение.текст}</div>`;
    }
    if (сообщение.вид === 'врезка') {
      return `<div class="dl-item dl-voice"><span class="dl-voice-title">[${сообщение.голос}]</span><br>${сообщение.текст}</div>`;
    }
    if (сообщение.вид === 'результат_проверки') {
      return `<div class="dl-item dl-check ${сообщение.успех ? 'win' : 'fail'}">${сообщение.текст}</div>`;
    }
    return '';
  }).join('');

  // Выводим ленту в контейнер
  $('plate').innerHTML = `<div class="dialogue-ledger" id="dl-scroll">${лентаHtml}</div><div id="acts"></div>`;
  
  // Автоскролл ленты в самый низ к свежим репликам
  const scrollBox = $('dl-scroll');
  if (scrollBox) scrollBox.scrollTop = scrollBox.scrollHeight;

  // Выводим выборы в #acts
  const доступные = получитьДоступныеВыборы(S, граф);
  const acts = $('acts');
  acts.innerHTML = '';
  
  доступные.forEach((выбор, i) => {
    const b = document.createElement('button');
    b.className = 'b';
    let тегПроверки = '';
    if (выбор.проверка) {
      const шанс = рассчитатьШанс(S, выбор);
      тегПроверки = `<span class="check-tag">[${выбор.проверка.название} ${шанс}%]</span>`;
    }
    b.innerHTML = `<span class="row"><span>${тегПроверки}${выбор.текст}</span></span>`;
    b.onclick = () => {
      сделатьВыборГрафа(S, граф, i);
      onШаг(S);
    };
    acts.appendChild(b);
  });
}
```

Этот набор кода сразу готов к работе. Он реализует открытые вероятности, проверки, телесные/профессиональные врезки в ключевых местах и ленту диалога.
