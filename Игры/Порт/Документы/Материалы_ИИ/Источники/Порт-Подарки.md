# Порт — концепт и задание: Подарки

Написано 20.09.2026. Отдельная механика, вне этапов §22. Не новая
экономика и не новая шкала — новое применение того, что уже есть (вещи,
распол), плюс закрывает строку, которая в ГДД уже написана, но никогда не
была реализована.

## Идея в одну строку

Вещь из восьми слотов можно не только съесть — можно отдать человеку,
которому симпатизируешь. Расположение растёт быстрее, чем от слов, но
платишь вещью, а не временем.

## Это уже обещано в ГДД, просто не сделано

§9: *«Табак… — И он же лучший подарок и валюта разговора.»* Строка есть с
самого начала работы над этим этапом игры, а ни подарков, ни табака как
вещи в коде нет — есть только «Ящик с табаком» в аптеке, чистая деталь для
осмотра, без действия купить. Эта механика не добавляет что-то новое поверх
концепции — закрывает то, что уже решено и написано, просто ещё не собрано.

## Механика

Любая вещь из `S.герой.при_себе` может быть подарена текущему собеседнику.
Никакого нового флага «подарочная вещь» не завожу — годится всё, что
лежит в слотах (сейчас это только пирог и табак, будет больше — из
`Данные/вещи.js`, без правки движка).

**Эффект:** вещь уходит из слотов, распол растёт — **+1**, либо **+2**,
если вещь совпадает с полем `любитПодарок` этого человека (новое,
необязательное поле в `ЛЮДИ`, по аналогии с уже существующими
`любит`/`обижает` про тон). Не у всех оно задано — по умолчанию любая вещь
даёт +1 и нейтральную реакцию.

**Ограничение:** один подарок одному человеку в один день (не хочется,
чтобы можно было скупить весь табак разом и поднять распол за один визит
до потолка). Флаг — `S.мир.люди[id].дарилДень` (число, день последнего
подарка), проверяется до показа кнопки.

## Где в коде — команда, не общая

`Движок/разговор.js`, `действияСцены()`, блок разговора (`с.собеседник`
истинен) — между уже существующим блоком `обмен` (строка ~522) и
`отойти()` (строка ~525):

```js
if (S.мир.люди[кто]?.дарилДень !== S.мир.день) {
  for (let i = 0; i < (S.герой.при_себе ?? []).length; i++) {
    const id = S.герой.при_себе[i];
    const в = вещь(id);
    if (!в) continue;
    добавить({ id: `подарить:${i}`, вид: 'подарить', текст: `Подарить: ${в.имя}` },
      S2 => подарить(S2, кто, i));
  }
}
```

`подарить(S, кто, i)` — новая функция, рядом с `положить`/`съесть` в
`Движок/вещи.js` (эта функция про вещь, не про сцену — правильное место):

```js
export function подарить(S, кто, i) {
  const id = S.герой.при_себе[i];
  const в = вещь(id);
  if (!в) return null;
  S.герой.при_себе.splice(i, 1);
  const л = (S.мир.люди[кто] ??= { спрошено: [], исчерпано: [] });
  const любит = л.любитПодарок === id;
  л.распол = Math.max(-2, Math.min(4, (л.распол || 0) + (любит ? 2 : 1)));
  л.дарилДень = S.мир.день;
  const с = `Подарил: ${в.имя}`;
  S.мир.журналДня.push(с);
  return с;
}
```

(Импорт `вещь` из `Данные/вещи.js` в `Движок/разговор.js` уже, скорее
всего, не нужен, если функция целиком лежит в `вещи.js` — оттуда и
дёргается.)

## Новые вещи

Сейчас в реестре одна вещь (пирог), дарить особо нечего. Минимум для
содержания — табак, раз он уже назван в ГДД лучшим подарком:

**`Данные/вещи.js`:**

```js
табак: { id: 'табак', имя: 'Щепоть табака', подписьСобой: 'Табак с собой' },
```

(без поля `еда` — не съедается, только дарится; система слотов уже это
допускает — `действияВещей` в `Движок/вещи.js` просто не создаёт для него
кнопку «Съесть», проверено по коду: цикл там пропускает вещи без `.еда`).

**Покупка — у Сибиллы, аптека** (деталь «Ящик с табаком» уже описывает
это словами, действия не было — добавляется): новое действие в комнате
аптеки, `Данные/Места/аптека.js`, рядом с существующими действиями:

```js
{ вид: 'купить-вещь', текст: 'Купить щепоть табака', вещь: 'табак', цена: 4 }
```

(конкретная реализация цикла покупки вещей — по образцу того, как уже
куплена еда в `Движок/действия.js`, тот же паттерн: списать деньги,
`положить(S, 'табак')`, если слоты не полны).

**Кому нравится (`любитПодарок`)** — расставить по двум существующим
людям, где это уже читается из написанного текста, без выдумывания новых
черт характера: старому бойцу в бане (уже вся его характеристика — про
табак и наколки соседствуют по тону) и моряку (естественная деталь для
человека с корабля). Остальным — без поля, дефолтная реакция.

```js
// Данные/Места/баня.js, ЛЮДИ.boec:
любитПодарок: 'табак',
// Данные/Места/таверна.js, ЛЮДИ.moryak:
любитПодарок: 'табак',
```

**Реакция при подарке** — короткий текст, отдельно от «вступления»,
показывается сразу после клика (`выполнить` уже возвращает строку в
журнал дня — этого достаточно технически; отдельная реплика в сцене —
опционально, украшение, не обязательное для работы механики):

> **Старый боец**, если подарен табак: «Табак настоящий. Спасибо — не
> ждал такого от чужого человека.» (распол +2)
>
> **Моряк**, если подарен табак: «О, южный. Давно такого в руках не
> держал.» (распол +2)
>
> **Любой другой человек, любая вещь** (нейтральная реакция, распол +1):
> «Смотрит на подарок, кивает — не откажется.»

## Решено

| Вопрос | Решение |
|---|---|
| Какие вещи можно дарить? | Любые из `при_себе`, без отдельного флага |
| Первая новая вещь | Табак — уже названа в ГДД §9, аптека уже описывает ящик словами |
| Лимит | Один подарок одному человеку в день (флаг `дарилДень`) |
| Новая шкала? | Нет — расход существующих слотов вещей, эффект на уже существующий распол |
| Стоит ли ограничивать дарение деньгами напрямую? | Нет — вещь и так стоит денег на покупку, второй платы не нужно |

## Задание

1. **`Данные/вещи.js`** — добавить `табак` (без `.еда`).
2. **`Данные/Места/аптека.js`** — действие покупки табака (см. выше;
   исполнитель сверяет точный формат действия с тем, как уже куплена еда в
   этом же файле/`действия.js` — вставить тем же паттерном, не изобретать
   новый).
3. **`Движок/вещи.js`** — функция `подарить(S, кто, i)`, экспортировать.
4. **`Движок/разговор.js`, `действияСцены()`** — блок «Подарить» в разделе
   разговора, как указано; импорт `вещь`, `подарить` из `Данные/вещи.js` /
   `Движок/вещи.js`.
5. **`Данные/Места/баня.js`, `Данные/Места/таверна.js`** — поле
   `любитПодарок: 'табак'` у `boec` и `moryak` соответственно; короткие
   реакции-тексты по образцу выше (опционально — если не добавить, оба
   получают дефолтную нейтральную реакцию, механика не ломается).
6. **Тест `Тесты/подарки.mjs`:** (а) подарок убирает вещь из слотов; (б)
   распол растёт на 1 или на 2 в зависимости от `любитПодарок`; (в) второй
   подарок тому же человеку в тот же день не проходит (кнопка не
   строится — проверить через `действияСцены`, не только через
   `подарить` напрямую); (г) распол не превышает потолок 4 даже при долгой
   серии подарков за разные дни.
7. **Браузер:** купить табак у Сибиллы → зайти в баню → подарить бойцу →
   реакция и рост распол; попробовать подарить второй раз в тот же день —
   кнопки уже нет.
