# Материалы ИИ

- [Источники](Источники/) — исходные концепты, тексты и задания от других моделей. Это материал для сверки, а не автоматически принятые решения.
- [Задания и результаты](Задания_И_Результаты/) — отправленные задания, ответы и редакторские решения. Начните с [описания четырёх заданий](Задания_И_Результаты/README.md) и [решений автора](Задания_И_Результаты/РЕШЕНИЯ_ПО_ЧЕРНОВИКАМ_ИИ.md).
- `Задания_И_Результаты/На_Разбор/` — материалы, ещё ожидающие оценки или внедрения.
- `Задания_И_Результаты/Шаг_1/`, `Шаг_14/`, `Шаг_17/` — пакеты по соответствующим шагам плана.

За фактическим внедрением следите по [реестру](../РЕЕСТР_ВНЕДРЕНИЯ_МАТЕРИАЛОВ_ИИ.md) и [журналу](../Порт-журнал.md).
