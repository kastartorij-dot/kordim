# Все присланные диалоги НПС

Здесь лежат **все 30 присланных персонажей подряд**, файлы `01–30`. Следующие персонажи добавляются сюда же, с продолжением нумерации. Общие файлы `00` каждой пачки также лежат здесь.

Это исходные черновики ИИ для авторской работы. Они сохранены без переписывания реплик и **пока не подключены к игре**. Для пачки 1 здесь последняя присланная исправленная редакция; ранние варианты сохранены [отдельно](../Пачка_1/README.md). Архивы и рецензии находятся рядом в папках `Пачка_1–6`.
