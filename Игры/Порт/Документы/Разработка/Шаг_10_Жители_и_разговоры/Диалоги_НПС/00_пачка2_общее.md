## 1. Правила, применённые в пачке (по рецензиям к пачке 1)

- Поля графа: выбор `{ид, текст, эффект, дальше}`, узел `при`, ветка `уже`, `исход`; расположение — `распол:{id:N}`, условие — `доверие`, диапазоны `[мин,макс]`.
- Ключ `один` не используется. Одноразовость текста и награды — через `нетФакта`/`нетФлага` и `исход`.
- У каждого `старт` ветки есть явный `уйти` (проверено скриптом по файлам пачки 2).
- Приветствие — по `факт знакомы` (знакомство с человеком), а не по визитам в место. Фоновый НПС: `вступление`/`снова`.
- Закрытие темы — флаг вечера, проверяемый в доступе ветки (`нетФлага`), с перечнем в `флагиВечера`. Закрывается только тема, не весь разговор.
- Знание выдаётся только явным `при` / `тема` / `слух` / `подтвердить` в нужном узле; строка «Знание:» в шапке — справка.
- Слух не повышается автоматически. Ярна выдаёт `тема:'dolgi_doma'` как показание самой Ярны (осознанно: это первичный источник); Сибилла — только `sinij_chas_sibilla`; Хозяин таверны ничего не выдаёт.
- Монета: списывается только в варианте со `стоит` + `деньгиОт` + `гроши`; где монета отвергается, стоит пометка «деньги не списываются».
- Награды ≤ +1 за поступок, один раз за вариант; оплата услуги не равна расположению.
- Вложенных переходов между ветками нет (возврат к источнику не используется).
- Новые детали — с меткой ⟦пр⟧ прямо в тексте и таблицей замены (§3).
- Проверок навыков нет: ни у Ярны, ни у значимых нет сцены, которая их требует. Пассивные голоса ЧУТЬЁ и МОЛВА у Ярны не влияют на ход.
