## Каркас (П1)

- Данные — [`Данные/связи.js`](../../../Данные/связи.js), правила — [`Движок/связи.js`](../../../Движок/связи.js), проверка — `Тесты/шаг11.mjs`.
- Состояние `S.мир.связи[кто]` создаётся лениво, версия сохранений остаётся **14**.
- **Доверие** — прежнее расположение из разговоров. **Влечение** (0–3) — только эффект личного момента графа. **Доступ** — счёт оплаченных вечеров; он не меняет ни доверия, ни этапа.
- Этапы: знакомство → встречи → вне-работы → поворот → решение → после. Первые два открываются сами (разные дни встреч и доверие 1), дальнейшие — эффектом графа `связь: { этап }`, только по одному.
- Её решение (`да | нет | дружба | позже`) — запись, которую не переписывают числа; примирение не снимает «нет».
- Отсутствие героя: у связи «вместе» через 6 дней без встречи — пауза, через 12 — расставание, обе строкой в журнале дня. Обещание со сроком: непросроченное можно сдержать, просроченное — нарушено и стоит доверия 1.
- Графы и места пользуются условием `если: { связь: { этапОт, этапДо, влечение, решение, статус, поступок, обещание, отсутствиеОт, доступОт, другаяСвязь, кто } }` и эффектом `связь: { этап, влечение, поступок, доверие, решение, обещание, сдержать, расстаться, примириться, кто }`.
- «Остаться» в комнате больше не прибавляет доверия (было +1 за оплату — источник PR001-16). Вторая сцена Фреи и Нии открывается доверием 2 из разговоров и этапом «встречи», а не ценой.
- Журнал → «Люди» → блок «Личное»: этап и решение словами, доверие, влечение и доступ отдельно, данные обещания.
- `npm run check` падает, если в данных мест есть сцена близости без файла в `Сцены/Близость/`.

## Замечания прогонов

[PR001-16](../../Прогоны/РЕЕСТР.md#pr001-16). Проверить развитие и разнообразие отношений, различие личного доверия и отношения дома. Цена услуги не обязана покупать хороший личный исход.
