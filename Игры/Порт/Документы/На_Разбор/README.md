# На разбор

Сюда автор складывает ответы других ИИ, документы, ZIP и патчи для будущей прочитки. Файлы этой папки не объявляются принятыми или внедрёнными.

**Обязательное правило:** после завершённого разбора сразу переносить файл в нужную по смыслу папку, без отдельной просьбы автора. В `На_Разбор` остаются новые и частично разобранные материалы; у частично разобранного файла нужно отметить, что осталось прочитать или проверить. Ожидание внедрения или утверждения предложений не задерживает перенос.

При разборе: прочитать материал, сверить с действующими данными и решениями, отметить противоречия и предложения, определить шаг по [плану](../Разработка/ПЛАН_17_ШАГОВ.md). Затем перенести материал в папку шага, сохранив исходный текст и отдельно записав решения; общий материал — в `Общие_Материалы/`. Отклонённую или заменённую редакцию сохранить в архиве с причиной. Обновить ссылки и README назначения.

Имена входящих файлов могут использовать старую нумерацию. Сверяйтесь с [таблицей соответствий](../Разработка/СООТВЕТСТВИЕ_СТАРЫХ_НОМЕРОВ.md). ZIP и патчи сначала проверяют; их наличие не означает, что код нужно применить.
