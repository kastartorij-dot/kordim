# На разбор

Сюда автор складывает ответы других ИИ, документы, zip и патчи. Файлы этой папки не считаются принятыми или внедрёнными.

После разбора файл сразу переносится, без отдельной просьбы автора:
- нужное в работе — в `../Материалы/`;
- отработанное или заменённое — в `../Архив/` с причиной;
- что из него ещё нужно сделать — строкой на [доску](../../ДОСКА.md).

Перенос не означает утверждения, канона или реализации. Патчи и zip сначала проверяют; их наличие не значит, что код нужно применить. Частично разобранный файл остаётся здесь с пометкой, что ещё прочитать.
