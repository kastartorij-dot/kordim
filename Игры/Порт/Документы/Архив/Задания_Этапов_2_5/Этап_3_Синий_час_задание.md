  `localStorage` — его запускает Node.
- Числа — только из этого задания и из старого кода. Непонятное — `// ВОПРОС:`

- **Не трогать:** `Канон/`, `Игры/Сайт/Приложение/`, `Игры/Генератор_Историй/Index.html`,

## Решения, принятые заранее

Чтобы не гадать. Если какое-то кажется неверным — сделать как написано и
записать возражение в журнал.

1. **Бюджет вечера — 12 часов, как в старой игре**, а не 4–6 ходов из ГДД §4.
   Это поле места (`часов: 12`), не константа движка. Иначе рушится баланс
   готовых реплик и проверка «один в один». Вопрос о 4–6 ходах — автору.
2. **Когда открыт:** только **вечером**, в **торговом квартале**. Зайти =
   потратить вечерний отрезок (списывается при входе, один раз). Когда
   выходишь — в городе уже **ночь**.
3. **Вход** — те же 20 гр. у двери, что и в старой игре. Развернулся на пороге
   — денег не потратил, но вечер ушёл.
4. **Одвин вместо четырёх героев.** Старые `поПерсонажу` и стартовые данные
   переходят на начала:

   | старый герой | начало Одвина | стартовые темы | дом при первом визите |
   |---|---|---|---|
   | `prikazchik` (с баржи) | `семья` | `ceny` | 0 |
   | `pisar` (писарь меняльной) | `бумаги` | `dolgi_doma` | 0 |
   | `iglica` (мастер наколок) | `наколки` | `nakolki` | 1 |
   | `naemnica` | — | — | — |

   Реплики `поПерсонажу.naemnica` в данных **сохранить** (текст не терять), но
   ключом они не сработают — у Одвина нет такого начала.
   Стартовые темы — в `Данные/герой.js`, полем `темы` у каждого начала (при
   новой игре они попадают в `S.мир.темы` вместе с `ni_o_chem`). Дом при
   первом визите — полем `знакомства: { 'синий-час': { дом: 1 } }` у
   наколок.
5. **Нож и жетон.** У Одвина нет ни того, ни другого, поэтому у двери сейчас
   одна ветка: «Заплатить и войти». Ветки с ножом и жетоном перенести в данные
   целиком, с условием «есть предмет `нож`» / «есть предмет `жетон`» (смотрится
   в `S.герой.при_себе`). Сейчас они просто не выпадают.
6. **Что дом помнит между визитами** (это и есть «место в городе»):

   | где | что | почему |
   |---|---|---|
   | `S.мир.места['синий-час']` | `дом` (−3…3), `долг`, `флаги` (постоянные), `осмотрено` | дом помнит, как ты себя вёл и сколько должен |
   | `S.мир.люди[id]` | `распол` (−2…4), `спрошено`, `исчерпано` | люди помнят разговор; спрошенное второй раз не даёт расположения — иначе его фармят визитами |
   | `S.мир.темы` | узнанные темы | темы общие для всего города (ГДД §11) |
   | `S.сцена` | комната, собеседник, подход, ветка, реплика, часы, вошёл, кошелёк на входе, флаги вечера | живёт только внутри визита |

   **Флаги вечера** сбрасываются на входе. Их список — полем места
   `флагиВечера: ['наверху', 'вино', 'музыка', 'вышла_niya', 'вышла_freya',
   'спрятал', 'сножом', 'вдолг']`. Все остальные флаги (`была_у_ярны`,
   `nsfw_niya`, …) постоянные.
7. **Откат** («назад») работает только внутри визита: снимок — весь `S` без
   `S.история`; на выходе из места `S.история` очищается (ГДД §21, правило 3).
8. **Финал вечера → выход в город.** Экран «Счёт вечера» и «Что осталось
   после тебя» — те же тексты и те же условия. Кнопка «Начать вечер заново»
   заменяется на «Выйти в город»; «Отменить последний шаг» остаётся. «Потрачено»
   считается от кошелька на входе, а не от стартовых денег героя.
9. **Сцены близости — отдельными файлами** (ГДД §17):
   `Игры/Порт/Сцены/Близость/niya_1.md` и `freya_1.md`, текст из старого
   `СЦЕНЫ_NSFW` дословно (включая строку `[ 18+ … ]`). Движок грузит файл по
   id через `fetch`; нет файла — показывает «Дальше — без слов.», как старый
   код. После сцены `S.герой.напряжение = 0` (ГДД §9; шкала пока ни на что
   не влияет, это нормально).
10. **Новое, чего не было** — одно: горячее у поварихи (ГДД §12). На кухне,
    если `распол` поварихи ≥ 2, действие «Поесть на кухне» — даром, 1 час,
    раз за визит: сыт +2, отдых +1. Текст (написан заранее, брать как есть):
    «Повариха, не поднимая головы, ставит на край стола миску и ложку. — Ешь,
    пока горячее. Не за деньги.»

## Шаг 2. Всё зашитое в функции — в данные

Мини-язык условий и эффектов, общий для всего места. **Условие** — объект, все
поля должны выполниться:

```js
{ флаг, нетФлага, домОт, распол: { кто, от }, предмет, деньгиОт, вошёл, началоЕсть }
```

**Эффект** — старый формат `э` (`час, гроши, дом, распол, тема, флаг`) плюс
`комната`, `вошёл`, `финал`, `долг`, `сыт`, `отдых`, `реплика`.

Что куда переезжает:

| в старом коде | в данных |
|---|---|
| `дверь()` — порог крыльца до входа | `КОМНАТЫ.krylco.вход: [действия]` с условиями `предмет: 'нож'` / `'жетон'` |
| вино и музыкант в зале | `КОМНАТЫ.zal.действия` |
| три пути к хозяйке (`была_у_ярны` / `дом>=1` / 40 гр.) | три действия в `zal.действия` с условиями |
| «Уйти через двор», «Выйти и пойти домой» | действия с эффектом `финал` |
| подъём наверх, «в долг» | уже поля комнаты (`цена`, `часы`) — движок делает это общо для любой платной комнаты |
| штраф за «прямо» у Олы и Фреи | поле человека `обижает: 'прямо'` |
| `комнатаЕё`, `послеСцены` | поле комнаты `хозяйка: 'niya'` |
| `вступление()` | поле человека `вступление` |
| `ОНА` | поле человека `она: true` |
| тексты `рисоватьФинал()` | `итоги: [{ если, заг, текст }]` по порядку, первое подошедшее |
| утечки | `утечки: [{ если, текст }]` |
| `фонДля()` | поле комнаты `градиент` |
| горячее у поварихи | `kuhnya.действия`, условие `распол: { кто: 'povariha', от: 2 }` |

## Шаг 3. Движок разговора — `Движок/разговор.js`

Чистая логика, по образцу `действия.js`:

- `войти(S, местоId)` — списать вечерний отрезок, собрать `S.сцена`, сбросить
  флаги вечера, при первом визите — `знакомства` из начала.
- `действияСцены(S)` → список `{ id, текст, подпись, можно, почему, выполнить }`
  — то же, что кнопки старой игры в текущей комнате или в разговоре: заговорить,
  рассмотреть, пойти, подняться, действия комнаты, темы, «продолжить» ветки,
  «остаться», отойти. Подход (прямо / мягко / деньгами) — отдельная функция
  `выбратьПодход`.
- `спросить`, `продолжитьВетку`, `применить`, `времяИдёт` — перенос старых
  функций с заменой `S.гроши` → `S.герой.кошель`, `S.распол` →
  `S.мир.люди[id].распол` и т.д. по таблице из решения 6.
- `выйти(S)` — посчитать итог (заг, текст, строки счёта, утечки), положить в
  `S.сцена.итог`; после «Выйти в город» — `S.сцена = null`, `S.история = []`.
- снимок и откат — внутри сцены.

Поведение один в один со старым: тот же порядок кнопок, тот же расход часов,
«повтор тем же тоном — тот же ответ, без часа и без расположения», те же
отговорки.

Коммит.
