# Архив документов

| Папка | Почему здесь |
|---|---|
| `Ранние_Концепты/` | идеи до действующего ГДД или проекты, которые он не заменяет целиком |
| `Задания_Этапов_2_5/` | поручения по уже выполненным ранним этапам и их черновые тексты |
| `Пакеты_Кода/` | patch и zip, сохранённые как история переноса; исходник игры находится вне архива |
| `Версии/` | редакции, которые получили уточнённый вариант |

Архивные материалы могут содержать старые пути, промежуточные решения и снятые формулировки. При работе над игрой начните с [навигатора](../README.md), [ГДД](../Порт_ГДД.md) и [текущего плана](../ПЛАН_ДОРАБОТКИ.md).
