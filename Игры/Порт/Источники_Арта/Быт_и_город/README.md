## Применение

Хлеб и ночлег под открытым небом доступны в нескольких районах: основные кадры нейтральные. Причальные версии в Варианты/ показывать только в доках. Каша у окна раздачи — новое ответвление трущоб; прежний стол на улице отклонён автором. Похлёбка в таверне — сцена доков, пирог на рынке — сцена покупки; не использовать её как универсальную еду из карманов. Мясо — сцена торгового района.

У ночлежки, койки в доках и комнаты вдовы нет закреплённых отдельных интерьеров: изображения — предложения для просмотра. Они не меняют канон и свойства ночлега. Знакомые места берутся из текущих игровых изображений; предметные крупные планы не закрепляют новую локацию.

## Подключение

Определить место показа каждого кадра: покупка, ночлег, уход, фон места, итог дня или предмет. Не вставлять узнаваемую локацию в универсальное действие. Копировать исходники в рабочие ресурсы при реализации; публикацию собирать штатным скриптом.

Предбанник для сушки — новый визуальный вариант при бане. Объединённый кадр бинта и настоя подходит разделу лечения, но не утверждает наличие обоих предметов у героя. Плащ показан с каплями: при подключении учитывать состояние одежды.
