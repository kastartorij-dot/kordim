# Карта проекта ПОРТ

Пути ниже относительно `Игры/Порт/`. Используйте строку своей задачи, затем найдите нужную функцию или данные. Документы всех 17 шагов — в [навигаторе](Документы/Разработка/README.md); не требуется читать их целиком перед каждой правкой.

| Задача | Где искать сначала | Проверка / документы |
|---|---|---|
| Прогон, фидбек, исправление замечаний | [Документы/Прогоны/README.md](Документы/Прогоны/README.md), [реестр](Документы/Прогоны/РЕЕСТР.md) | Отчёт конкретной версии → ID → ведущий шаг → исправление → повторная проверка |
| Запуск, подключение экранов, стили | `index.html` | Локальный просмотр; шаг 14 |
| Экран города, места, панель, меню | `Движок/экраны.js`, `экраны-места.js`, `экраны-панель.js`, `меню.js` | `Тесты/прогон.mjs`, `память-места.mjs`; шаг 14 |
| Сохранение, миграции, новое состояние | `Движок/состояние.js`, `Данные/герой.js` | `Тесты/шаг2.mjs`, `вещи.mjs`; шаг 2 |
| Действия, время, эффекты, сроки | `Движок/действия.js`, `время.js`, `эффекты.js`, `сроки.js`, `шаг.js` | `Тесты/шаг2.mjs`, `прогон.mjs`; шаги 2, 9 |
| Вещи, одежда, тело, хранение | `Движок/вещи.js`, `одежда.js`, `тело.js`, `хозяйство.js`; соответствующие `Данные/*.js` | `Тесты/шаг3.mjs`, `вещи.mjs`; шаг 3 |
| Диалоги, ветки, проверки, голоса | `Движок/диалог.js`, `разговор.js`, `голоса.js`, `проверка.js`; `Данные/Диалоги/`, `Данные/Места/` | `Тесты/диалоги.mjs`; пилот — шаг 4, остальные жители — шаг 10 |
| Работы, случаи, обучение, последствия | `Данные/работы.js`, `Данные/Смены/`; `Движок/смена.js`, `последствия-работ.js`, `ремёсла.js` | `Тесты/работы*.mjs`, `шаг5*.mjs`; шаг 5 |
| Дела жителей и награды | `Данные/дела.js`, `Движок/дела.js`, действия и диалоги участников | `Тесты/дела.mjs`; шаг 6 |
| Подарки, слухи, дневник | `Движок/шаг7.js`, `шаг7-адаптер.js`, `подарки.js`, `слухи.js`; `Данные/подарки.js`, `слухи-о-герое.js`, `голос.js` | `Тесты/шаг7.mjs`, `шаг7-интеграция.mjs`; шаг 7 |
| Районы, места, жители и свидетельства | `Данные/районы.js`, `места.js`, `Места/`, `свидетельства.js` | `Тесты/шаг8.mjs`, `память-места.mjs`; шаги 8–10 |
| Сцены близости и личные линии | `Сцены/Близость/`, `Данные/Места/синий-час.js`, диалоги | Шаг 11; условия проверять с действующим движком |
| Портреты и фоны | `Ресурсы/`, `Источники_Арта/` | `Документы/АРТ_РЕЕСТР.md`, шаг 14 |
| Реестр жителей, выгрузка диалогов | `Документы/Разработка/Шаг_10_Жители_и_разговоры/` | `Скрипты/собрать-диалоги.mjs`; шаг 10 |
| Все присланные черновики диалогов 01–20 | `Документы/Разработка/Шаг_10_Жители_и_разговоры/Диалоги_НПС/` | Одна папка с последовательной нумерацией; архивы и рецензии — в соседних `Пачка_1–4/`; тексты не подключены |
| Сборка для сайта | `Скрипты/publish.mjs`, `publish-stories.mjs`, `check-published.mjs` | `npm run publish-all`, `npm run check` |
| Windows-оболочка | `Приложение_Для_ПК/` | Её README; версия оболочки не является версией всей игры |

Схема: `index.html` подключает движок; движок читает игровые данные; скрипт публикации копирует игровые файлы в `Игры/Сайт/Игра/Порт/`. Документы, тесты и исходники арта в публичную копию не входят.

Новые факты мира проверяются по мастер-канону и вносятся по общим правилам Кордима. Исправление кода само по себе не требует чтения всего мастер-канона.
