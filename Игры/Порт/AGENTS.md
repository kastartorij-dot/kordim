# ПОРТ — инструкции для работы

Рабочие исходники находятся здесь, в `Игры/Порт/`. Общие правила Кордима из корневого AGENTS.md остаются в силе. Старая папка `D:/AI/kordim/Порт` пустая и не является проектом.

- В начале сессии проверить Git и выполнить `git pull`; порядок синхронизации — `Документы/ПОРЯДОК_РАБОТЫ_И_ВЕРСИЯ.md`. В этой папке может параллельно работать другая сессия: не делать `git pull --autostash`, коммитить только свои файлы.
- **Что делать дальше и где мы сейчас — `ДОСКА.md`.** Это единственный список задач: решения автора, вычитка, работа по направлениям, остаток плана шагов 12–17. Сделанное отмечать там же; новое, что нашлось по ходу, дописывать туда, а не в отдельный документ.
- Для поиска нужной системы использовать `КАРТА_ПРОЕКТА.md`. Сначала искать функции и разделы через `rg`, затем читать найденный участок и зависимости. Не читать целиком ГДД, план или выгрузку диалогов ради небольшой задачи.
- Полные требования шагов и раздел «Готово» — в `Документы/ПЛАН_ДОРАБОТКИ.md`. Номера шагов Ш01–Ш17 те же, что в реестре прогонов.
- Нужные в работе документы — в `Документы/Материалы/` (сюжет и цели, жители и диалоги, отношения, мини-игры, места, вещи, концепты). Отработанное — в `Документы/Архив/`, его не правят. Новых документов не заводить: итог работы — сообщение коммита и строка на доске.
- `Документы/На_Разбор/` — входящая папка автора. После разбора файл сразу переносить: нужное в `Материалы/`, отработанное в `Архив/`, оставшиеся задачи строкой на доску. Перенос не означает утверждения, канона или реализации; патчи не применять автоматически.
- Прогоны и замечания ведутся по `Документы/Прогоны/README.md`. Перед работой открыть связанные ID в `Документы/Прогоны/РЕЕСТР.md`; новые наблюдения привязать к шагу, повторы добавлять к существующему ID. После исправления записать коммит и результат проверки по критерию. «Учтено в плане» не означает «проверено».
- Текущий код и данные — `index.html`, `Движок/`, `Данные/`, `Сцены/`, `Ресурсы/`. В `Ресурсы/` только то, что игра использует: оно уходит на сайт. Варианты и кандидаты — в `Источники_Арта/`. Копию `../Сайт/Игра/Порт/` собирает скрипт; её не правят руками.
- Выгрузку диалогов `Документы/Материалы/Жители/ВСЕ_ДИАЛОГИ_НПС.md` пересобирать `node Скрипты/собрать-диалоги.mjs`. Снимок текстов работ `Документы/Материалы/Работы/Шаг_5_тексты_игры.md` собирает `Тесты/тексты-работ-в-md.mjs`. Результаты сквозных партий тесты пишут в `Тесты/Результаты/`.
- После правки — обязательные проверки и публикация из порядка работы. Не объявлять весь набор зелёным, если какие-то проверки падают.
- При изменении путей обновлять ссылки, генераторы и проверки; при изменении структуры — карту проекта.
- Содержательные изменения сохранять через осмысленный commit и push. При отклонении push — rebase и повторная проверка.
