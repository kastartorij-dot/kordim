Порядок синхронизации и правило единственной версии: [ПОРЯДОК_РАБОТЫ_И_ВЕРСИЯ.md](Документы/ПОРЯДОК_РАБОТЫ_И_ВЕРСИЯ.md).

лежат в этой папке.

## Текущий этап

Этапы 1–5 исходного ГДД реализованы; это играбельная ранняя сборка.
Актуальный порядок — [план полной игры](Документы/ПЛАН_ДОРАБОТКИ.md) с общей нумерацией от 05.10.2026:
17 шагов, четыре амбиции, все материалы других ИИ, два сезона и проверенный выпуск.
Второй сезон разрабатывается последним, после полной готовности и проверки первого.
Рабочий слой подарков, слухов и дневника уже встроен. [Статус Шага 7](Документы/Разработка/Шаг_07_Память_города/Шаг_7_память_города.md): механики проверены; сюжетную приёмку сверять с уже подключёнными делами Шага 6 и текущими тестами.
Остальные шаги сверять с [планом](Документы/ПЛАН_ДОРАБОТКИ.md) и [реестром](Документы/РЕЕСТР_ВНЕДРЕНИЯ_МАТЕРИАЛОВ_ИИ.md).
Новые факты мира сверяются с каноном, решения и фактическое внедрение — с ГДД и журналом.

## Проверка и публикация

Нужен Node.js. Из корня репозитория:

```powershell
Get-ChildItem Игры/Порт/Тесты/*.mjs | ForEach-Object {
  node $_.FullName
  if ($LASTEXITCODE -ne 0) { throw "Провал: $($_.Name)" }
}
node Игры/Порт/Скрипты/publish.mjs
```

Сборка обновляет `Игры/Сайт/Игра/Порт/`; именно она публикуется Cloudflare Workers
после push в `main`. Документы, тесты и `Источники_Арта/` туда не копируются. Для
локального просмотра запустить `Игры/Сайт/_serve.ps1` и открыть
`http://localhost:8791/Игра/Порт/`. Двойной щелчок по `index.html` не работает:
модулям нужен HTTP-сервер. Генератор историй открывается отдельно на
`/Игра/Истории/`.

Windows-приложение не содержит копию игровых файлов: оно открывает этот же
публичный адрес в отдельном окне WebView2. Поэтому после правки игры достаточно
обычной публикации через GitHub → Cloudflare — пересобирать установщик не нужно.
Установщик пересобирается workflow `Сборка Порта Теней для Windows` только при
изменении самой оболочки в `Приложение_Для_ПК/`.

Не редактировать `Игры/Сайт/Игра/Порт/` вручную: правки потеряются при следующей
сборке. Для новых картинок сначала определить их роль по арт-реестру, затем
поместить в `Ресурсы/` и подключить через Данные/Движок. Часовню и крест не
менять; непиксельные изображения пока допустимы.
