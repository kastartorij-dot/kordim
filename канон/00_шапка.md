# Кордим — полный канон

Карточка персонажей и лорбук `World_GraceAndNobody_v4`, переведённые из JSON и XML в обычный текст. Записей пятьдесят три: сорок восемь из исходного файла (0–47), три дописаны по аркам (48–50), 51 «Быт и материальность» и 52 «Отряд Лихо» внесены 13.09. Разметки нет, служебных полей нет; ключи каждой записи оставлены отдельной строкой — они понадобятся, если запись будет возвращаться в SillyTavern.

Год примерно 1026-й, ранняя осень.

**Что это за файл.** Полная версия, а не сжатая: перенесено всё содержимое исходников. Для загрузки контекстом в чат есть отдельный краткий файл — этот нужен как мастер-документ, из которого краткий пересобирается.

**Оговорка про источник.** Материал извлечён из PDF, а PDF оказался лоссовым: при рендере в нём местами потерялись пробелы на переносах строк. Я восстановил их статистически по всему корпусу — исправлены тысячи мест, — но пара десятков слипшихся слов могла уцелеть. Смысл нигде не пострадал.
