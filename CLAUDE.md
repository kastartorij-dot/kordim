Авторский мир «Грейс и Никто». Год в сюжете ~1026, ранняя осень. Магии нет.
С 13.09.2026 мир не гримдарк: физика реальная, тон спокойный, в жизни есть свет.

## Канон — блоки, мастер собирается из них

С 15.09.2026 канон режется на отдельные файлы, `00_КАНОН_Мастер_Кордим.md` руками
**не редактируется** — он собирается скриптом. Подробно и порядок правки — в
`канон/_build/README.md`, коротко:

| Где | Что |
|---|---|
| `канон/герои/`, `канон/правила/`, `канон/записи/` (53 файла, 0–52), `канон/приложения/` | сами блоки, каждый — YAML-шапка + дословный текст |
| `канон/00_шапка.md` | обложка и журнал правок |
| `канон/манифест.json` | порядок сборки, генерируется `split.mjs`, руками не трогать |
| `канон/00_КАНОН_Мастер_Кордим.md` | **продукт сборки** (`node канон/_build/build.mjs`), единственный источник истины по смыслу, но не по редактированию |
| `канон/01_Компакт_канон.md` | пока отдельный документ, в сборку не входит (организован по темам, не по номерам записей) |
| `канон/02_Очередь_и_вопросы.md` | не канон, а работа: открытые вопросы автора, что отыграть, что дописать, кандидаты в НПС, заметки к прозе, матчасть |

Правка мира = правка нужного блока + `build.mjs` (пересобрать мастер) +
`validate.mjs` (проверить на снятые формулировки) + строка в журнале правок
(`00_шапка.md`) + догнать компакт вручную.

**Не канон:** `архив/` (там же `архив/источники_канона/` — PDF, реестр, исходники
решений 26.08 и свод 13.09; всё из них уже внесено в мастер или в очередь),
`черновики/`, `проза/`.

## Git — обязательно для любой сессии

С 15.09.2026 папка — приватный репозиторий `github.com/kastartorij-dot/kordim`. Это единственный
способ, которым правки долетают между разными чатами и устройствами (ПК, облачный Code на телефоне).

- **В начале сессии**, если репозиторий уже клонирован не только что: `git pull`, чтобы не разойтись
  с правками из других сессий.
- **После любой содержательной правки файлов** (канон, данные вики, промты, код) — `git add -A`,
  осмысленный `git commit`, `git push`. Не копить правки молча до конца дня: если сессия прерывается
  или параллельно работает другая, несохранённое пропадёт или столкнётся конфликтом.
- Если `git push` отклонён (кто-то запушил раньше) — `git pull --rebase`, разрешить конфликт, запушить
  снова. Не форсить (`--force`) без явной просьбы автора.
- Автор физически не может параллельно редактировать эту же папку с телефона напрямую — с телефона он
  либо работает в облачном Code (свой клон, синк через git, как описано выше), либо в обычном проекте
  Claude (только читает подключённые файлы, писать в репозиторий не может). Обычный чат никогда не
  меняет репозиторий сам — правки оттуда попадают сюда только через явную синхронизацию.

## Что ещё в папке

- `wiki/app/` — **новый проект мира** (с 14.09). Запуск: конфиг `wiki` в `.claude/launch.json`
  (PowerShell, только Windows) или `wiki-py` (`python3 -m http.server`, кроссплатформенно,
  но без раздачи `/game/` — это делает только `_serve.ps1`), адрес `http://localhost:8791/app/`.
  Стиль «Хроника», страница персонажа — раскладка «Панели».
  Разделы: Главная, Люди, Места, Фракции, Карта, Хроника, Мир, Вопросы, Игра.
  - `data/` — **правда о мире для проекта**. Автор правит мир в чате, правки вносятся сюда
    (и в мастер-канон, пока текстовый мастер не собирается из данных автоматически).
    `people.js` — реестр людей; полный профиль с хронологией по годам — отдельный файл
    в `data/people/` (сейчас только `elowen.js`, следующая — Грейс). `places.js`, `routes.js`,
    `factions.js`, `events.js`, `articles.js`, `questions.js`.
  - `js/views/` — по модулю на раздел, `js/ui.js` — карта, «в путь», пиксель, разговоры.
  - Вкладка «Игра» — iframe на `Мини-игра/Index.html`; `_serve.ps1` отдаёт её по `/game/`.
  - Разговоры с пометкой `draft:true` — наброски, автор их не подтверждал.
- `wiki/index.html` — старый справочник, отстаёт от 13.09 (Гильдия, валюта); заменяется
  проектом. `wiki/proto/` — прототипы дизайна, по которым выбирали стиль.
- `Мини-игра/` — текстовая RPG по миру на OpenRouter; устройство и планы в её `.md`.
- `персонажи/` — лица и кандидаты в НПС (`ЛИЦА.html`, запуск через `.claude/launch.json`, конфиг `faces`).
- `проза/` — сцены (арка Лихо во Вратах).
- `черновики/` — НПС на одобрение автора.
- `graphify-out/` — граф знаний, MCP `kordim-graph`. **Пока не трогаем** (решение автора).
  **В репозитории этой папки нет** — она живёт только на ПК автора, путь в `.mcp.json`
  windows-only, поэтому в облачных сессиях сервер `kordim-graph` не подключается (это
  ожидаемо, не чинить самостоятельно). Не пересобирался с 27.08: по конторе, деньгам,
  населению и жетонам врёт, там проверять по мастеру. Метки связей: `EXTRACTED` — прямо,
  `INFERRED` — выведено, `AMBIGUOUS` — открытый вопрос автора (только с оговоркой).
