# Порт Теней — отдельный проект игры

Игра отделена от первой RPG с OpenRouter: её код, тесты, документы и изображения
лежат в этой папке. `Мини-игра/` остаётся самостоятельным старым проектом.
Публичный адрес игры: `https://kordim.kastartorij.workers.dev/game/port/`.

| [Решения по черновикам ИИ](документы/задания-другим-ИИ/РЕШЕНИЯ_ПО_ЧЕРНОВИКАМ_ИИ.md) | принятые правила и проверки после плейтеста |

Исторические задания и журнал в `документы/` могут называть старые пути
`Мини-игра/Порт/` и `wiki/img/port/`. Это история, а не текущая инструкция.

## Текущий этап

Этапы 1–5 исходного ГДД реализованы; это играбельная ранняя сборка.
Актуальный порядок — [план полной игры](документы/ПЛАН_ДОРАБОТКИ.md) от 29.09.2026:
22 пакета, четыре амбиции, все материалы других ИИ, два сезона и проверенный выпуск.
Второй сезон разрабатывается последним, после полной готовности и проверки первого.
Рабочий слой подарков, слухов и дневника уже встроен. [Статус Шага 7](документы/Шаг_7_память_города.md): механики проверены, но четыре слуха ждут пяти дел Шага 6 для полного прохождения.
Остальные пакеты сверять с [планом](документы/ПЛАН_ДОРАБОТКИ.md) и [реестром](документы/РЕЕСТР_ВНЕДРЕНИЯ_МАТЕРИАЛОВ_ИИ.md).
Новые факты мира сверяются с каноном, решения и фактическое внедрение — с ГДД и журналом.

## Проверка и публикация

Нужен Node.js. Из корня репозитория:

```powershell
Get-ChildItem Порт/тест/*.mjs | ForEach-Object {
  node $_.FullName
  if ($LASTEXITCODE -ne 0) { throw "Провал: $($_.Name)" }
}
node Порт/scripts/publish.mjs
```

Сборка обновляет `wiki/game/port/`; именно она публикуется Cloudflare Workers
после push в `main`. Документы, тесты и `art-src/` туда не копируются. Для
локального просмотра запустить `wiki/_serve.ps1` и открыть
`http://localhost:8791/game/port/`. Двойной щелчок по `index.html` не работает:
модулям нужен HTTP-сервер. Старый проект открывается отдельно на
`/game/Index.html`.

Windows-приложение не содержит копию игровых файлов: оно открывает этот же
публичный адрес в отдельном окне WebView2. Поэтому после правки игры достаточно
обычной публикации через GitHub → Cloudflare — пересобирать установщик не нужно.
Установщик пересобирается workflow `Сборка Порта Теней для Windows` только при
изменении самой оболочки в `desktop/`.

Не редактировать `wiki/game/port/` вручную: правки потеряются при следующей
сборке. Для новых картинок сначала определить их роль по арт-реестру, затем
поместить в `assets/` и подключить через данные/движок. Часовню и крест не
менять; непиксельные изображения пока допустимы.
