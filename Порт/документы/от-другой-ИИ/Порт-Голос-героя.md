# Порт — концепт и задание: Голос героя

Написано 20.09.2026. Отдельная механика, вне этапов §22. Самая дешёвая из
трёх: один маленький счётчик, который нигде не показывается сам по себе,
один реестр текстов, одна точка проверки в конце дня.

## Идея в одну строку

Раз в несколько дней — короткая запись от первого лица: как герой сам про
себя думает сейчас. Не хроника мира (`S.мир.хроника` — это факты дня, для
всех одинаковые по форме), а голос — меняется от того, как игрок его вёл.

## Первое, что нужно закрыть: это не противоречит §10?

§10 ГДД: «нельзя добавить шкалу, для которой нельзя назвать три конкретных
места, где она меняет игру». Счётчик тона ниже (`S.герой.тон`) — **не
шкала в этом смысле**. Он не открывает и не закрывает ни одной двери, не
меняет ни одной цены, не решает, доступна ли реплика — ровно как
`S.мир.люди[id].спрошено` (список заданных тем) не «стат», а служебная
память. Единственное, на что влияет счётчик тона, — какую из уже написанных
записей голоса показать. Если когда-нибудь возникнет соблазн дать ему
второй эффект (например, сделать так, чтобы высокий счётчик «деньгами»
менял цены) — вот тогда он станет стат ом по правилу §10, и его придётся
обосновывать тремя эффектами уже всерьёз. Пока — не становится.

## Механика

**`S.герой.тон`** — три счётчика, растут при каждом успешно заданном
вопросе по теме (не за каждый клик — только там, где ответ реально
состоялся):

```js
тон: { прямо: 0, мягко: 0, деньгами: 0 }
```

Инкремент — в `движок/разговор.js`, функция `спросить(S, тид)`, в том же
месте, где сейчас `л.спрошено.push(тид + ':' + с.подход)` (эта строка уже
есть в коде — рядом с ней, тем же вызовом): `S.герой.тон[с.подход] =
(S.герой.тон[с.подход] ?? 0) + 1`.

**`S.герой.голос`** — массив уже показанных id (как `S.мир.флаги`, только
у героя). Проверка — раз в день, `закончитьДень`, не каждый день подряд:
только если `S.мир.день` кратен трём **или** сработало особое условие
(см. реестр — у части записей есть свой день или факт, не только тон).

```js
export function обновитьГолос(S, итог) {
  if (S.мир.день % 3 !== 0 && !ГОЛОС_ВНЕОЧЕРЕДИ.some(id => подходит(S, id))) return;
  for (const [id, з] of Object.entries(ГОЛОС)) {
    if (S.герой.голос.includes(id)) continue;
    if (з.условие(S)) { S.герой.голос.push(id); return; } // не больше одной записи за день
  }
}
```

(`return` после первой добавленной — по одной записи в день с запасом,
иначе за один день может набежать сразу три подходящих сразу после
пропущенной недели, и это будет читаться как спам, а не как голос).

## Где это видно

Новый раздел «Голос» на экране «Журнал», рядом с «Дни» — список коротких
записей в порядке появления, без дня в подписи (голос не хроника, дата ему
не нужна, важен сам факт, что он прозвучал). Реализация — тот же паттерн,
что «Дела»/«Темы»: `движок/сводка.js`, `сводкаЖурнала(S)`:

```js
голос: (S.герой.голос ?? []).map(id => ГОЛОС[id]?.текст).filter(Boolean),
```

## Решено

| Вопрос | Решение |
|---|---|
| Это стат? | Нет — обоснование выше, счётчик тона не открывает ничего |
| Может повлиять на диалог/цены? | Нет, никогда, этим специально не становится |
| Частота | Не чаще одной записи в три дня, кроме трёх «внеочередных» (день 15, день 25, первый кризис тела) |
| Зависит от «Дел»? | Одна запись (`pomog_ne_za_dengi`) — мягко, с защитой `?? {}`; остальные семь — нет |
| Порядок записей в реестре | От конкретного факта к счётчику — то же правило §10, что в «Слухах о герое» |

## Задание

1. **`движок/состояние.js`** — `новоеСостояние()`: `S.герой.тон: { прямо: 0, мягко: 0, деньгами: 0 }`, `S.герой.голос: []`.
2. **`данные/голос.js`** — реестр `ГОЛОС` и `ГОЛОС_ВНЕОЧЕРЕДИ`, ровно как
   выше (тексты — черновик, автор может переписать каждую строку без
   последствий для механики: условие и текст разделены).
3. **`движок/разговор.js`, `спросить(S, тид)`** — добавить инкремент
   `S.герой.тон[с.подход]` рядом с существующим `л.спрошено.push(...)`.
4. **`движок/время.js`, `закончитьДень`** — вызвать `обновитьГолос(S, итог)`
   (новая функция, в `движок/голос.js` или прямо в файле реестра — по
   вкусу исполнителя, логики там меньше десяти строк, отдельный файл
   не обязателен).
5. **`движок/сводка.js`** — поле `голос` в `сводкаЖурнала`, как выше.
6. **`движок/экраны-панель.js`** — раздел «Голос» на экране «Журнал».
7. **Тест `тест/голос.mjs`:** (а) при нулевых счётчиках и дне < 7 ничего не
   добавляется; (б) `nedelya_molchal` не срабатывает, если счётчики не
   нулевые (не должен конфликтовать с «vezde_*» записями); (в) не больше
   одной новой записи в один вызов `обновитьГолос`; (г) `pervyy_krizis`
   срабатывает вне зависимости от того, кратен ли день трём.
