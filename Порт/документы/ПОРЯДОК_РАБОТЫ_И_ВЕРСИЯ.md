# Порядок работы и версия игры

Рабочая папка ПОРТа — `Порт/` в корне репозитория `kordim`.

`Порт/` — единственный источник игры. Внутри него лежат код, данные, тесты, документы и исходные изображения.

`Порт/site/game/port/` — не вторая рабочая версия, а автоматически собранная копия для сайта. Её не редактируют вручную. Она создаётся командой `npm run publish` из исходников `Порт/`.

Старый отдельный проект удалён; его архивные упоминания не являются рабочей инструкцией.

## Как версии совпадают

Версия игры — один коммит ветки `main` в GitHub `kastartorij-dot/kordim`. В коммит с изменениями игры входят исходники `Порт/` и результат сборки `Порт/site/game/port/`. После этого выполняется один `git push origin main`.

Номер сохранения (`12` сейчас) — совместимость данных, а не номер выпуска. `0.1.0` в desktop — версия Windows-оболочки, а не всей игры.

## Порядок каждой сессии

Перед началом:

```powershell
git switch main
git pull --rebase origin main
```

После правки:

```powershell
npm run publish
npm run check
Get-ChildItem тест/*.mjs | ForEach-Object { node $_.FullName; if ($LASTEXITCODE -ne 0) { throw "Провал: $($_.Name)" } }
git status
git add -A
git commit -m "понятное описание изменения"
git push origin main
```

Если push отклонён, выполнить `git pull --rebase origin main`, снова `npm run publish`, `npm run check`, затем push.

Статус читается так: «в игре» означает код и проверку; «частично» — работает только первый слой; «материал» — документ, ZIP или картинка без подключения; «не начато» — только план.
