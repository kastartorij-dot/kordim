# Реестр внедрения материалов других ИИ

**29.09.2026.** Порядок обновлён: второй сезон — П21, после готового и проверенного первого сезона. Приложение к [плану полной игры](ПЛАН_ДОРАБОТКИ.md). Цель — обеспечить перенос всего содержания из 15 исходников, сохранив возможность проверить каждый пункт.

Статус **учтено** означает, что место в плане назначено. **Подготовлено** — есть согласованная схема/отредактированные данные. **Встроено** — работает в игре. **Проверено** — есть пройденный пользовательский путь и профильная проверка. До реализации строку нельзя закрыть только потому, что её текст существует.

При выполнении пакета к строке добавляются: целевой файл, id реализации, существенная правка относительно источника и проверка. Если два источника описывают одну функцию, они ссылаются на одну реализацию; содержание не требуется дублировать.

## 6. Как закрывать реестр

На приёмке проверяются не только числа. Для каждого случая нужны сохранённые варианты и последствия, для механики — действующий экран, для сюжетного задела — потребитель и развязка. Изменения id/имён/формул записываются рядом со строкой источника. Все исправленные противоречия сверяются с разделом 3 основного плана.
