# Архив документов

| Папка | Почему здесь |
|---|---|
| `ранние-концепты/` | идеи до действующего ГДД или проекты, которые он не заменяет целиком |
| `задания-этапов-2-5/` | поручения по уже выполненным ранним этапам и их черновые тексты |
| `пакеты-кода/` | patch и zip, сохранённые как история переноса; исходник игры находится вне архива |
| `версии/` | редакции, которые получили уточнённый вариант |

Архивные материалы могут содержать старые пути, промежуточные решения и снятые формулировки. При работе над игрой начните с [навигатора](../README.md), [ГДД](../Порт_ГДД.md) и [текущего плана](../ПЛАН_ДОРАБОТКИ.md).
