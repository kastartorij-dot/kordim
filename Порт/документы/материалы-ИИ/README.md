# Материалы ИИ

- [Источники](источники/) — исходные концепты, тексты и задания от других моделей. Это материал для сверки, а не автоматически принятые решения.
- [Задания и результаты](задания-и-результаты/) — отправленные задания, ответы и редакторские решения. Начните с [описания четырёх заданий](задания-и-результаты/README.md) и [решений автора](задания-и-результаты/РЕШЕНИЯ_ПО_ЧЕРНОВИКАМ_ИИ.md).
- `задания-и-результаты/на-разбор/` — материалы, ещё ожидающие оценки или внедрения.
- `задания-и-результаты/шаг-1/`, `шаг-14/`, `шаг-17/` — пакеты по соответствующим шагам плана.

За фактическим внедрением следите по [реестру](../РЕЕСТР_ВНЕДРЕНИЯ_МАТЕРИАЛОВ_ИИ.md) и [журналу](../Порт-журнал.md).
